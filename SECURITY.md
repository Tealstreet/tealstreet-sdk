# Security

Please do not report security problems in a public issue, pull request or
discussion.

## Reporting a vulnerability

- **Once this repository is public:** use GitHub's private vulnerability
  reporting (the repository's **Security** tab, then **Report a vulnerability**).
- **Until then:** contact a Tealstreet maintainer privately.

Include the affected package or file, how to reproduce the problem, and what an
attacker could do with it. We will acknowledge the report and keep you updated
while we fix it.

## Scope

This repository holds client code: the `safe-cex` exchange SDK, the Tealstreet
CLI and their shared packages. Reports about credential handling, request
signing, the proxy and tunnel transports, and dependency supply chain are
especially welcome.
