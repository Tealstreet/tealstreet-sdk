## Connecting [Bitrue](https://teal.link/bitrue) to Tealstreet

- First, make sure you are logged into your [Bitrue](https://teal.link/bitrue) account.

:::note
Consider supporting Tealstreet by using the [Bitrue Referral Link](https://teal.link/bitrue).
:::

<IntroTealstreet exchangeName="Bitrue" />

---

### Creating the key

- Now you are ready to generate the API Keys within your Bitrue Account. Head on over to the [Bitrue](https://teal.link/bitrue) tab and:
  - Click on the User Icon.
    - Select **API** from the dropdown menu.

<div class="text--center">
    <img src={ApiDropdown} alt="Api Dropdown" style={{ width: 800 }} />
</div>

- On the API Key page click on the **Get API Key** Button to start the key creation process.

<div class="text--center">
    <img src={ApiCreate} alt="Get Api Key" style={{ width: 600 }} />
</div>

:::tip
You can get to this page directly by navigating to **[this link](https://www.bitrue.com/bitrue-api)**
:::

- Now you are ready to setup your [Bitrue](https://teal.link/bitrue) API Key pair.

:::caution
Bitrue requires users to complete KYC before they can trade on the platform.
You also need to have 2FA enabled on your account to create an API key.
:::

- Choose a name for your key. It can be whatever you want.

<div class="text--center">
    <img src={ApiName} alt="New API Name" style={{ width: 500 }} />
</div>

- If you did not yet activate 2FA you will see a popup informing you to activate it.

<div class="text--center">
    <img src={Api2FA} alt="API Created" style={{ width: 500 }} />
</div>

:::note
You can access your security settings by [clicking here](https://www.bitrue.com/user/security)
:::

- If you have enabled 2FA you will be told to visit your email to confirm the creation of the API key.
  - Once you click the link in your email you will be taken to the API key page

<div class="text--center">
    <img src={ApiCreated} alt="API Created2" style={{ width: 500 }} />
</div>

- Securely store your API Key and API Secret. You will need these later when we go to link them in Tealstreet.
  - In the API Settings enable **Orders & Positions** permission.

:::warning
You **MUST complete KYC** or you will not be permitted to enable the 'Orders & Posititions' API permission.
:::

- Put the IP's from the Tealstreet window into the IP Whitelist box on the Bitrue API page.

<div class="text--center">
    <img src={ApiWhitelist} alt="API Creation" style={{ width: 500 }} />
</div>

- Click **Save Settings**.

If you enabled 2FA and completed KYC, you should now have a new API key pair. Lets take the information you got and go back to Tealstreet to finish linking the key.

---

### Connecting the key to Tealstreet

Now let us proceed back to where we left the Tealstreet API page:

<div class="text--center">
    <img src={ApiTeal} alt="Api Creation2" style={{ width: 600 }} />
</div>

- Proceed to fill out the form with the information you got when you created the API on the Bitrue API page.
    <!-- - Ensure **Use TS Network** is checked unless you intend handle IP Whitelisting in some other way. --> - Give the key a name, this can be anything you want. - Choose the color you want your API to be in the terminal. - Provide the **API Key** Bitrue showed you when you created the API. - Provide the **API Secret** Bitrue showed you when you created the API. - Click '**Done**'.
