## Connecting [Breakout](https://teal.link/breakout) to Tealstreet

- First, make sure you are logged into your [Breakout](https://teal.link/breakout) account.

:::note
Consider supporting Tealstreet by using the [Breakout Referral Link](https://teal.link/breakout).
:::

- Next, log into your [Tealstreet](http://v3.tealstreet.io/trade) account.

:::tip
It's a good idea to keep both Tealstreet and [Breakout](https://teal.link/breakout) tabs open.
:::

- Click the '**Settings**' button near the top right corner of the terminal.

<div class="text--center">
    <img src={AddingApi} alt="Adding API" style={{width: 900},{height: 75}} />
</div>

- Click the '**Add new key**' button at the bottom of the settings page.

<div class="text--center">
    <img src={Dropdown} alt="TS Dropdown" style={{ width: 600 }} />
</div>

- Choose **Breakout** from the exchange selection menu.

<div class="text--center">
    <img src={ExchangeSelection} alt="Exchange Selection" style={{ width: 600 }} />
</div>

Okay lets go back to our **Breakout** account and create the API Key.

---

### Creating the key

- Now you are ready to generate the API Keys within your Breakout Account. Head on over to the [Breakout](https://teal.link/breakout) tab and:
  - Click on the User Icon.
    - Select **API Management** from the dropdown menu.

<div class="text--center">
    <img src={ApiDropdown} alt="Api Dropdown" style={{ width: 300 }} />
</div>

- On the API Key page click on the **Create API** Button to start the key creation process.

<div class="text--center">
    <img src={ApiCreate} alt="Api Create" style={{ width: 700 }} />
</div>

<!-- :::tip
You can get to this page directly by navigating to **[this link](https://bingx.com/en-us/account/api/)**
::: -->

- Now you are ready to choose the settings of your [Breakout](https://teal.link/breakout) API Key pair.

- Pass your security verification if the window pops up.

<div class="text--center">
    <img src={SecVerify} alt="Security Verify" style={{ width: 400 }} />
</div>

- Now you're key shouldve be created, however its settings will not be correct yet so we need to edit it:

<div class="text--center">
    <img src={ApiCreated} alt="API Created" style={{ width: 500 }} />
</div>

- Here we will be ticking the box to permit perpetual futures, as well as the checkbox to restrict IP addresses.

<div class="text--center">
    <img src={ApiCreated2} alt="API Created2" style={{ width: 500 }} />
</div>

- Now would be a good time to bring back your Tealstreet terminal API page from where we left off earlier to get the recommended IP addresses:

<div class="text--center">
    <img src={ApiWhitelist} alt="API Creation" style={{ width: 500 }} />
</div>

- Copy these IP addresses to your clipboard with the clip button
  - paste them into the restricted IP's box on the Breakout API page.

<div class="text--center">
    <img src={ApiCreation3} alt="API Creation3" style={{ width: 500 }} />
</div>

- After editing the settings, click the **Save** button.

### Connecting the key to Tealstreet

Now let us proceed back to where we left the Tealstreet API page:

<div class="text--center">
    <img src={ApiTeal} alt="Api Creation2" style={{ width: 600 }} />
</div>

- Proceed to fill out the form with the information you got when you created the API on the Breakout API page.
  - Ensure **Use TS Network** is checked unless you intend handle IP Whitelisting in some other way.
  - Give the key a name, this can be anything you want.
  - Choose the color you want your API to be in the terminal.
  - Provide the **API Key** Breakout showed you when you created the API.
  - Provide the **API Secret** Breakout showed you when you created the API.
  - Click Done.

:::caution
Never share your API Keys with anyone. Tealstreet team members will never ask you what your API key is.
:::

:::info
Be sure to double check you do not confuse **API Key** and **API Secret.** Connecting your **[Breakout](https://teal.link/breakout)** exchange account to Tealstreet will not work if these fields are not entered correctly.
:::

If all the details are correct, you will have successfully linked your [Breakout](https://teal.link/breakout) account to Tealstreet.

- Close options and navigate to the Main Trading page of the Tealstreet terminal and select the [Breakout](https://teal.link/breakout) account you just linked to enable it.
  - If properly linked, you will see your balance appear in the Margin window of Tealstreet. Happy trading!!!
