## Connecting [ApeX Omni](https://teal.link/apex) to Tealstreet

- First, make sure you are logged into your [ApeX Omni](https://teal.link/apex) account.

:::note
Consider supporting Tealstreet by using the _[ApeX Omni referral link](https://teal.link/apex)._
:::

<IntroTealstreet exchangeName="ApeX Omni" />

---

### Connecting the wallet to ApeX

- Open the [ApeX Omni](https://teal.link/apex) website.
- Click on the **Connect Wallet** option.

<div class="text--center">
    <img src={Apex1} alt="Connecting the Wallet" style={{ width: 400 }} />
</div>

- Choose to connect via wallet or email.
  - For this guide, we will be using the wallet option.

<div class="text--center">
    <img src={Apex2} alt="Choose wallet or email" style={{ width: 400 }} />
</div>

- Select the wallet you want to connect.
  - For this guide we will be using the [Rabby Wallet](https://rabby.io/).

<div class="text--center">
    <img src={Apex3} alt="Choosing which wallet" style={{ width: 300 }} />
</div>

- Sign the transaction to confirm the wallet connection.

<div class="text--center">
    <img src={Apex4} alt="Signing the tx to confirm wallet" style={{ width: 500 }} />
</div>

- Click the wallet profile to access the settings for the connected wallet.

<div class="text--center">
    <img src={Apex5} alt="Accessing settings for connected allet" style={{ width: 400 }} />
</div>

- Navigate to the **API Management** settings window.
  - You can click here to go to the [API settings](https://omni.apex.exchange/keyManagement) page.

<div class="text--center">
    <img src={Apex6} alt="Accessing API Management option" style={{ width: 300 }} />
</div>

---

### Creating the Omni Key

- Click **Omni Key**.

<div class="text--center">
    <img src={Apex7} alt="Creating the Omni Key" style={{ width: 700 }} />
</div>

- Read the security terms for the Omni Key.
  - Check **I understand** and click **Next** to proceed with the creation of the Omni Key.

<div class="text--center">
    <img src={Apex8} alt="Omni Key security agreement" style={{ width: 400 }} />
</div>

- You will receive a popup window with the Omni Key.
  - Keep the Omni Key handy as we will use it later in this guide

<div class="text--center">
    <img src={Apex9} alt="Omni Key receipt" style={{ width: 400 }} />
</div>

:::warning
Be sure to keep your Omni Key safe. Tealstreet team members will **never** ask you for your Omni Key.
:::

---

### Creating the API Key

- Navigate back to the [API settings](https://omni.apex.exchange/keyManagement) page.
  - Click **Generate API** to create a new API Key.

<div class="text--center">
    <img src={Apex10} alt="Generate the API Key from Api Settings" style={{ width: 700 }} />
</div>

- Give the Key a name. This can be whatever you want.
- Choose the option to restrict the key to specific IP's.
  - You can find the IP's inside the Tealstreet terminal tab we left open earlier.

:::warning
ApeX is an exchange we route through our servers for reliability and performance reasons. So it is not currently possible to use Tealstreet on ApeX while whitelisting IP's other then Tealstreet's.
:::

- Click **Confirm** to generate the API Key.

<div class="text--center">
    <img src={Apex11} alt="Setting up the API Key" style={{ width: 400 }} />
</div>

- You will be shown a popup window with the API Key, API Secret and Passphrase.
  - Save these somewhere as you will need them later in this guide.

<div class="text--center">
    <img src={Apex16} alt="Api Key Receipt" style={{ width: 400 }} />
</div>

:::warning
Be sure to keep your API Key info safe. Tealstreet team members will **never** ask you for your API Key details.
:::

---

### Enabling USDT Trading & depositing USDT

- Return to the dashboard and access the funds deposit window.

<div class="text--center">
    <img src={Apex12} alt="Accessing funds deposit window" style={{ width: 300 }} />
</div>

- Choose a chain to deposit USDT on.
  - For this guide we will be using the **Arbitrum** chain.
- Enable USDT trading on your account.

<div class="text--center">
    <img src={Apex13} alt="Enabling USDT" style={{ width: 300 }} />
</div>

- Sign the transaction to enable USDT.

<div class="text--center">
    <img src={Apex14} alt="Signing the USDT Enablement transaction" style={{ width: 300 }} />
</div>

- Click the **Transfer** button below the deposit button we just used.
  - Move the funds you deposited from the funding account to your perp account.

<div class="text--center">
    <img src={Apex15} alt="Transfer funds to perp wallet or deposit to perp wallet" style={{ width: 300 }} />
</div>

- With this we are all done with the ApeX side of the setup. Lets proceed back to the Tealstreet tab we opened earlier.

---

### Connecting the key to Tealstreet

Now let us proceed back to where we left the Tealstreet API page:

<div class="text--center">
    <img src={ApiTeal} alt="Api Creation2" style={{ width: 600 }} />
</div>

- Proceed to fill out the form with the information you got when you created the API on the ApeX API page.
  - Give the key a name, this can be anything you want.
  - Choose the color you want your API to be in the terminal.
  - (Optional) Enable Tealstreet Websocket if you have unreliable internet.
  - Provide the **API Key** ApeX showed you when you created the API.
  - Provide the **API Secret** ApeX showed you when you created the API.
  - Provide the **Passphrase** ApeX showed you when you created the API.
  - Provide the **Omni Key Seed** ApeX had you create before you could make the API.
  - Click '**Done**'.

## Troubleshooting

- I am getting this error "Order Size must be greater than 0. Order size is 0" why is this happening?
  - At this time Apex Omni does not support Full TP/SL. Please enable Partial TP/SL in your settings to place stoplosses for orders on Apex Omni.

- I am placing orders and theyre not appearing on the chart what is happening?
  - Your API Key might be expired or invalid. Please try making a new API key and seeing if that fixes the issue.

- I am getting an error that says 'L2 signature error, please check your wallet and re-sign.' what is happening?
  - Make sure you are whitelisting Tealstreet IP's when you create your key. We currently require whitelisting our IPs to be able to properly place orders on Apex Omni.
