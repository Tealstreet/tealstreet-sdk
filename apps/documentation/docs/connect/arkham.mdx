## Connecting [Arkham](https://teal.link/arkm) to Tealstreet

Arkham is a cryptocurrency derivatives exchange offering perpetual futures trading with competitive fees and deep liquidity. The platform provides institutional-grade trading infrastructure with a focus on transparency and performance.

<IntroTealstreet exchangeName="Arkham" />

---

### Creating the API Key

- Now we are ready to generate the API Key. Head on over to [Arkham](https://teal.link/arkm) and:
    - Login or create your account if you haven't already

Once you have logged in:

1. Click on the settings gear icon in the top right corner of the page
2. Select **API** from the topbar categories

<div class="text--center">
    <img src={ApiDropdown} alt="API Dropdown" style={{ width: 500 }} />
</div>

:::tip
You can get to this page directly by navigating to the **[Api Settings](https://arkm.com/settings/api)** page.
:::

---

### API Key Settings

Click the **Create API Key** button to start the key creation process.

<div class="text--center">
    <img src={ApiManagement} alt="API Management" style={{ width: 700 }} />
</div>

- **Name your API Key**: Choose a descriptive name (e.g., "Tealstreet")
    - This name only shows on Arkham's website for your reference

- **Permissions**: Ensure the following permissions are enabled:
    - **Enable Read** - Required for fetching account data
    - **Enable Write** - Required for placing orders
        <!-- * Do **NOT** enable Withdraw permissions -->

<div class="text--center">
    <img src={ApiCreate} alt="API Create" style={{ width: 600 }} />
</div>

:::note
IP whitelisting is not currently supported for Arkham.
:::

<!-- :::info
IP whitelisting adds an extra layer of security by ensuring only Tealstreet's servers can access your API.

- Click **Next** to generate your API Key \* If you have not completed KYC, you will get an error and be unable to create the API Key. Complete the KYC process and try again.
    <div class="text--center">

    </div>

- **Save your credentials**: Copy and store your **API Key** and **API Secret** securely
    - The API Secret is typically only shown once, so make sure to save it immediately

:::caution
Never share your API Keys with anyone. Tealstreet team members will never ask you what your API key is.
:::

### Connecting the key to Tealstreet

Now back to where we left the Tealstreet API page:

<div class="text--center">
    <img src={ApiTeal} alt="Arkham API Form" style={{ width: 600 }} />
</div>

- Proceed to fill out the form with the information you got when you created the API on the Arkham website:
  - **Name**: Give the key a name, this can be anything you want.
  - **Color**: Choose the color you want your API to be in the terminal.
  - **API Key**: The API Key you created on Arkham.
  - **API Secret**: The API Secret you received when creating the key.
  - Click the **Done** button.

## Troubleshooting

### API Key Not Working

**Problem**: Unable to connect or receive authentication errors.

**Solution**:
* Verify that both the API Key and API Secret are entered correctly
* Ensure you have enabled the correct permissions (Read and Trade)
* Check that the IP whitelist includes all Tealstreet IPs
* Make sure your API key has not expired

### Balance Shows 0

**Problem**: Connected successfully but balance shows zero.

**Solution**:
* Ensure you have deposited funds into your Arkham futures/trading account
* Some exchanges require funds to be transferred from spot to futures wallet
* Wait a few seconds and refresh the page

### Order Placement Errors

**Problem**: Unable to place orders or receiving permission errors.

**Solution**:
* Verify that **Trade** permission is enabled on your API key
* Check if you are trading in a restricted region
* Ensure you have sufficient margin/collateral for the order

### IP Whitelist Issues

**Problem**: Receiving IP-related errors.

**Solution**:
* Double-check that all Tealstreet IPs are added to your whitelist
* Ensure there are no typos in the IP addresses
* If issues persist, try removing the IP whitelist temporarily to test (then re-add for security) -->
