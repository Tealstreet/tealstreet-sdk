## Connecting [BingX](https://teal.link/bingx20) to Tealstreet

- First, make sure you are logged into your [BingX](https://teal.link/bingx20) account.

:::note
Consider supporting Tealstreet by using the [BingX Referral Link](https://teal.link/bingx20).
:::

<IntroTealstreet exchangeName="BingX" />

### Creating the key

- Now you are ready to generate the API Keys within your BingX Account. Head on over to the [BingX](https://teal.link/bingx20) tab and:
  - Click on the User Icon.
    - Select **API Management** from the dropdown menu.

<div class="text--center">
    <img src={ApiDropdown} alt="Api Dropdown" style={{ width: 300 }} />
</div>

- On the API Key page click on the **Create API** Button to start the key creation process.

<div class="text--center">
    <img src={ApiCreate} alt="Api Create" style={{ width: 700 }} />
</div>

:::tip
You can get to this page directly by navigating to **[this link](https://bingx.com/en-us/account/api/)**
:::

- Now you are ready to choose the settings of your [BingX](https://teal.link/bingx20) API Key pair.

- Pass your security verification if the window pops up.

<div class="text--center">
    <img src={SecVerify} alt="Security Verify" style={{ width: 400 }} />
</div>

- Now you're key shouldve be created, however its settings will not be correct yet so we need to edit it:

<div class="text--center">
    <img src={ApiCreated} alt="API Created" style={{ width: 500 }} />
</div>

- Here we will be ticking the box to permit perpetual futures, as well as the checkbox to restrict IP addresses.

<div class="text--center">
    <img src={ApiCreated2} alt="API Created2" style={{ width: 500 }} />
</div>

- Now would be a good time to bring back your Tealstreet terminal API page from where we left off earlier to get the recommended IP addresses:

<div class="text--center">
    <img src={ApiWhitelist} alt="API Creation" style={{ width: 500 }} />
</div>

- Copy these IP addresses to your clipboard with the clip button
  - paste them into the restricted IP's box on the BingX API page.

<div class="text--center">
    <img src={ApiCreation3} alt="API Creation3" style={{ width: 500 }} />
</div>

- After editing the settings, click the **Save** button.

---

### Activating Futures on the account

- Now we need to activate the derivatives futures on the account:
  - Go to the derivatives section and click the green activate button

<div class="text--center">
    <img src={ActivateFuts} alt="Activate Futures" style={{ width: 500 }} />
</div>

- Next we will have to go through some disclaimer stuff and agree to the terms and conditions.

<div class="text--center">
    <img src={ActivateFuts2} alt="Activate Futures2" style={{ width: 500 }} />
</div>

- Once you pass through the disclaimer portion you're account should be activated for futures trading.

:::note
If you do not activate futures trading on your account you will not be able to execute futures trades on Tealstreet.
:::

## Troubleshooting

- During May 2022 **BingX** deprecated their old API. If you are receiving an error about inability to decrypt the password and the API stopped working please switch to the V3 release of Tealstreet. Read more about [v3 here](/docs/about/version-3).

- I am seeing a message about insufficient margin when trying to place an order?
  - This is likely to have occurred if you have not transferred any funds to your **Perpetual Futures** account.
    - By default funds transfer into the **Standard Futures** account.

- I am seeing a message about "risk forbidden" in my order window?
  - Please double check your API key permissions you used when making the API.
        - Some users have reported they fixed it by remaking their API with the correct permissions.

## Frequently Asked Questions

- I can't use BingX coin-m? \* Coin-M is not currently supported on V3 of Tealstreet.

- Can I trade all of BingX's perpetual tickers in Tealstreet? \* Unfortunately around Aug 23 2024 BingX started restricting certain pairs for trading via the api to encourage users to use the website. Can read more about it at [Bingx support article](https://bingx.com/en/support/articles/36745491595801/)

- I am getting a generic error trying to link my API key on BingX it keeps saying refresh browser? \* Around July 2024 BingX upgraded their API which broke support for V2 of Tealstreet. Please switch to [V3](https://preview.tealstreet.io/trade)

- Can users trade BingX's Standard Futures like Stocks, Forex, and Indices through Tealstreet?
  - No. At the time of this writing **BingX** does not offer a open API for their Standard Futures. Tealstreet users can only trade BingX's Perpetuals.

- Am I limited in the amount of leverage I can use in perp futures?
  - Yes. BingX has certain restrictions for users who do not KYC when trading on certain pairs. (BTC and ETH are generally exempt from this restriction)

    :::note
    For more info please check out the [BingX Documentation](https://bingx.com/en-us/support/articles/360045899754-PerpetualFuturesPasanganPerdaganganLeveragedanLimit/)
    :::

- Can I change my margin from Isolated to Cross?
  - Yes. BingX defaults users to isolated but you can change it to cross. In the top right corner of the perp trading page you will see a button called Margin next to the Leverage indicator. Click it.

  - Yes you can use One-Way mode.
