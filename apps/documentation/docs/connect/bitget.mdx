## Connecting [Bitget](https://teal.link/Bitget) to Tealstreet

- First, make sure you are logged into your [Bitget](https://teal.link/Bitget) account.

:::note
Consider supporting Tealstreet by using the [referral link](https://teal.link/Bitget).
:::

<IntroTealstreet exchangeName="Bitget" />

---

- Now you are ready to generate the API Keys within your Bitget Account. Head on over to the [Bitget](https://teal.link/Bitget) tab and:
    - Click on the User Icon.
    - Select **API Management** from the dropdown menu.

<div class="text--center">

![API-Dropdown](/img/connect/bitget/apidropdown.png)

</div>

- On the API Key page click on the **Create New Key** Button to start the key creation process.

![API-Create](/img/connect/bitget/apicreate.png)

- Choose System Generated API Key

<div class="text--center">
    <img src={ApiCreate2} alt="Api Creation 2" style={{ width: 400 }} />
</div>

:::tip
You can get to this page directly by navigating to **[this link](https://www.bitget.com/en/account/newapi)**
:::

---

### Create New API

- Now you are ready to choose the settings of your [Bitget](https://teal.link/Bitget) API Key pair.

<div class="text--center">
    <img src={ApiMore} alt="Api Detailed" style={{ width: 400 }} />
</div>

1. Choose a nickname for the API Key pair on Bitget. This will only show on Bitget’s website, on the API management page.
    - It does not need to match the nickname you use on the Tealstreet terminal and it can be whatever you want.

2. Create an **‘API Passphrase.’** The passphrase must be at least 8 characters in length. Use only letters or numbers. Do not use symbols or special characters.
    - Store the **‘API Passphrase’** somewhere safe! You will need to enter this passphrase within the Tealstreet trading terminal.

3. Select the **'Read-Write'** permission

4. Scroll down

<div class="text--center">
    <img src={ApiMore3} alt="API More 3" style={{ width: 500 }} />
</div>

5. Choose the **Orders & Holdings** permission under **futures** category.

6. Scroll down further.

<div class="text--center">
    <img src={ApiMore4} alt="API More 4" style={{ width: 500 }} />
</div>

7. Select the **'Query'** permission under Taxation category.

:::note
This permission is necessary for the position history and journaling functionality of the terminal, however if you dont care about those features you can skip this particular permission.
:::

8. Copy and paste the IP addresses as listed within the Tealstreet trading terminal once you’ve selected Bitget from the dropdown menu.
    - Click the 'Clipboard' button from inside the terminal like in the below image.

<div class="text--center">
    <img src={ApiWhitelist} alt="API Whitelist" style={{ width: 500 }} />
</div>

9. Click **'Next'** to finalize the API Creation process.

<div class="text--center">
    <img src={ApiMore5} alt="API More 5" style={{ width: 500 }} />
</div>

10. Click the 'Send' button to get a code in your email account and then put this code in the email verification box

11. Enter your 2FA Auth code

12. Click **‘Confirm’** after completing all the necessary fields and Bitget will generate your API Key.

<div class="text--center">
    <img src={ApiMore6} alt="API More 6" style={{ width: 500 }} />
</div>

- Keep your **‘API Key’** & **‘SecretKey’** safe, we will use them to finish linking the API to Tealstreet.

:::caution
Never share your API Keys with anyone.
:::

---

### Connecting to Tealstreet

Once you have created the API Key on [Bitget's](https://teal.link/Bitget) website, you are ready to fill out the information on Tealstreet’s API creation page.

<div class="text--center">
    <img src={ApiTeal} alt="API Tealstreet" style={{ width: 650 }} />
</div>

- Choose a name for your Bitget Account API Key. This can be anything you want.

- Choose the color you want for this API Key. It can be whatever you want.

- Paste the **Bitget API Key** you created on the exchange website here.

- Paste the **Bitget API Secret** you created on the exchange website here.

- Paste the **Bitget API Passphrase** you created on the exchange website here.

- Click **‘Done’**.

<OutroTealstreet exchangeName="Bitget" />

## Troubleshooting Bitget

Below is a list of common issues reported for **Bitget**.

### Error message when trying to link an API key

When trying to create/link an API key I sometimes get an error message pop-up in Chinese. Why?

![Bitget-RegionRestricted](/img/connect/bitget/bitget-tradingregionrestricted.png)

- The exchange itself is sending this message which translates to: **you are restricted from placing orders due to regulatory restrictions**
    - This can occur if the exchange detects you are trading from a restricted region. This is not a Tealstreet issue, it is a decision made by the exchange.

---

### Error message when trying to place a stoploss

When trying to place a stoploss without a position, or trying to place a 2nd stoploss after a position has already been opened I get an error about insufficient position size. Why?

![Bitget-StoplossError](/img/connect/bitget/bitget-stoperror.png)

- This is a known issue with the exchange. The exchange does not allow you to place a stoploss without a position, or to place a 2nd stoploss after a position has been opened. This is not a Tealstreet issue, this is a design choice by the exchange.

### Why can't I set stops to use limits?

As of this writing Bitget does not currently support stoplosses using limit orders.
