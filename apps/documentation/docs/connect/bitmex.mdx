## Connecting [BitMex](https://teal.link/BitMEX) to Tealstreet

:::caution BitMEX exchange wind-down

BitMEX has [announced](https://www.bitmex.com/blog/bitmex-closure) that it has stopped new account registrations and will close exchange services on **September 23, 2026 at 04:00 UTC**.

Existing BitMEX users can continue using Tealstreet during the wind-down, but BitMEX will switch to reduce-only mode on **August 26, 2026 at 04:00 UTC**. From that point, only position-reducing trades are expected to be available, and BitMEX may force close open positions before the final closure time. Close open positions and withdraw funds as soon as practical.

:::

<!-- :::note
IP Whitelisting is mandatory to connect your BitMEX API to Tealstreet
::: -->

Follow the steps below:

- First, make sure you are logged into your existing **[BitMex](https://teal.link/BitMEX)** account. New BitMEX account registrations are no longer available as of July 23, 2026.

<IntroTealstreet exchangeName="Bitmex" />

---

### API Keys

- Now you are ready to generate the API Keys within your BitMex Account. Head on over to the BitMex tab and:

- Click on account.

- Select API Keys.

<div class="text--center">

![api-connect](/img/connect/bitmex/api-connect.png)

</div>

:::note
Visit the **[BitMex API](https://www.bitmex.com/app/apiKeysUsage)** documentation page if you want more information.
:::

---

### BitMex API Settings

- Now you are ready to create the API. On the Create an API Key page:

<div class="text--center">
    <img src={ApiMore} alt="API Detailed" style={{ width: 700 }} />
</div>

1. First, choose a name for your API Key. This is helpful for traders who utilize multiple exchanges and/or sub accounts and want to distinguish between them. This name is visible only on the BitMEX website.

2. Copy the **Whitelist IP Addresses** supplied by the **Tealstreet trading terminal** (on the new API key page) and paste them into the CIDR field.
    - You will need to enable to Use Tealstreet Network checkbox to see the IP Addresses.

3. Choose order on 'Key Permissions.'

4. Ensure that 'Withdraw' is unchecked.

5. Click ‘Create API Key.’

6. Now you have your API Key. The **API secret code** will not be available once you leave the page so either write it down or copy and paste.

<div class="text--center">

![api-example](/img/connect/bitmex/apiex.png)

</div>

:::caution
Do not share your API keys with anyone. Make sure you stored your **key & secret** in a safe place.
:::

- Once you have created the API Key on BitMex’s website, you are ready to fill out the information on Tealstreet’s **API Keys** page in the settings.

<div class="text--center">
    <img src={ApiTeal} alt="API Tealstreet" style={{ width: 650 }} />
</div>

- Ensure you have selected ‘BitMex’ in the Exchange selection menu.

<!-- * Enable 'Use Tealstreet Network' unless you will be doing custom ip whitelisting -->

- Choose a name for this API connection. You will see the name on an API dropdown list on the trading page of the Tealstreet terminal. This is helpful for traders who utilize multiple accounts and/or sub accounts per exchange and want to distinguish between them.

- Choose the color you want this API Key to be.

- Paste the API Key provided by BitMex here.

- Paste the API Secret provided by BitMex here.

- Click ‘Done.’

## Frequently Asked Questions

Can I trade on Tealstreet with a BitMex sub-account?

- Yes BitMex sub-accounts are supported.

I saw BitMex has a Leverage Booster option, can I use it?

- Yes, you can use the Leverage Booster option. However enabling it will prevent you from being able to switch between cross and iso margin.
