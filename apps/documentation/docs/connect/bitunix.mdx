## Connecting [Bitunix](https://teal.link/bitunix) to Tealstreet

- First, make sure you are logged into your [Bitunix](https://teal.link/bitunix) account.

:::note
Consider supporting Tealstreet by using the _[referral link](https://teal.link/bitunix)._
:::

<IntroTealstreet exchangeName="Bitunix" />

---

### Creating the key

- Now you are ready to generate the API Keys within your Bitunix Account. Head on over to the [Bitunix](https://teal.link/bitunix) tab and:
    - Click on the User Icon.
    - Select **API** from the dropdown menu.

<div class="text--center">
    <img src={ApiDropdown} alt="Api Dropdown" style={{ width: 300 }} />
</div>

- On the API Key page click on the **Create API** Button to start the key creation process.

<div class="text--center">
    <img src={ApiCreate} alt="Api Create" style={{ width: 700 }} />
</div>

:::note
You can access this page directly by [navigating here](https://www.bitunix.com/account/api-management).
:::

- Now you are ready to setup your [Bitunix](https://teal.link/bitunix) API Key.

<!-- :::warning
There is currently a bug on Bitunix' side which doesn't permit IP whitelisting. We hope this will be fixed soon. Until it is fixed do not whitelist IP's for your API Key.
::: -->

- Choose a name for your API Key, this can be anything you want.
    - Ensure **Trading API** is selected.
        <!-- * Ensure **IP Binding** is filled with the IP's provided in the Tealstreet API creation window. -->
    - Ensure **Permission** is set to **Trade**.
    - When ready click the **Get Code** button to receive a verification code via email. Then put the code in the box near the bottom.
    - Click the **Submit** button at the bottom of the page.

- Now you're key shouldve be created. Make sure you keep this information secure and handy as we will use it inside the Tealstreet terminal.

<div class="text--center">
    <img src={ApiCreated} alt="API Created" style={{ width: 500 }} />
</div>

:::caution
Tealstreet team members will never ask you what your API key is. Never share your API Keys with anyone.
:::

---

### Connecting the key to Tealstreet

Now let us proceed back to where we left the Tealstreet API page:

<div class="text--center">
    <img src={ApiTeal} alt="Api Teal" style={{ width: 700 }} />
</div>

:::warning
There is currently a bug on Bitunix' side which doesn't permit IP whitelisting. We hope this will be fixed soon. Until it is fixed do not whitelist IP's for your API Key.
:::

- Proceed to fill out the form with the information you got when you created the API on the Bitunix API page.
  - Enter your **Bitunix Access Code**.
    - This is a code you will receive via email when you ask us for it. [Details here](https://www.tealstreet.io/post/bitunix-api-keys-now-requires-use-of-tealstreets-bitunix-referral-link).
  - Give the key a name, this can be anything you want.
  - Choose the color you want your API to be in the terminal.
  - Provide the **API Key** Bitunix showed you when you created the API.
  - Provide the **API Secret** Bitunix showed you when you created the API.
  - Click Done.

## Bitunix Access Code

- **Bitunix Access Codes are now required** to add Bitunix API Keys in Tealstreet v3 due to updates in Bitunix’s system and policies.
- **How to get your Access Code:**  
  Email [support@tealstreet.io](mailto:support@tealstreet.io) with your Bitunix UID and your Tealstreet account email.  
  _Access Codes are unique and can only be used once._
- **Eligibility:**  
  You must use the [Tealstreet referral link](https://teal.link/bitunix) to register your Bitunix account. If you already have a Bitunix account, you’ll need to create a new one with the referral link for the Access Code.
- **Benefits:**  
  Registering via the Tealstreet referral link gives you a **35% rebate on Futures** and **25% rebate on Spot** trading.
- The Tealstreet team hopes this Access Code requirement will be removed in the future when Bitunix updates their system.
- **Alternative exchanges:**  
  If you do not wish to use the referral link or Access Code, consider using BloFin, Bybit, OKX, or Phemex instead.
