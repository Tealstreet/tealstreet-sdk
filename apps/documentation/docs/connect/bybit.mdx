## Connecting [Bybit](https://teal.link/bybit1) to Tealstreet

- First, make sure you are logged into your [Bybit](https://teal.link/bybit1) account.

<IntroTealstreet exchangeName="Bybit" />

---

Now you are ready to generate the API Keys within your Bybit Account. Head on over to the Bybit tab and: - Click on the User Icon. - Select **API** from the dropdown menu.

<div class="text--center">
    <img src={ApiDropdown} alt="API Dropdown" style={{ width: 550 }} />
</div>

- On the API Key page click on the **Create New Key** Button to start the key creation process.

<div class="text--center">
    <img src={ApiCreate} alt="API Create" style={{ width: 550 }} />
</div>

:::tip
You can get to this page directly by navigating to **[this link](https://www.bybit.com/app/user/api-management)**

    - Choose system generated API key.

- Now you are ready to choose the settings of your Bybit API Key pair.

5. Double check all the selections are correct and then click ‘Submit’.
    - A popup will appear next and prompt you to submit your 2FA code if its linked to your Bybit account.
    - Once you submit the 2FA code, you will see a new popup from Bybit with your API Key details. You need to paste those details into the API Key page of Tealstreet.

### Tealstreet API Creation

- Once you have created the API Key on Bybit’s website, you are ready to fill out the information on Tealstreet’s API KEYS page.

<div class="text--center">
    <img src={ApiTealstreet} alt="Tealstreet API" style={{ width: 650 }} />
</div>

- Ensure you have **Bybit** selected as the exchange.

<Admonition type="note" title="Bybit Brazil accounts">
    If your Bybit account is registered under Bybit Brazil, tick **Bybit Brazil account** in the Tealstreet API key form. This sends Bybit's required `x-site-id: BRA_BTL` header. You do not need to create a new Bybit API key just to change this Tealstreet setting.
</Admonition>

<!-- * Consider supporting Tealstreet by using the referral [link](https://teal.link/bybit1). -->

- Enable **Use Tealstreet Network** unless you intend to route your orders from some other location.
  - Adjust your whitelisted IP's accordingly.

<!-- * Choose the region you would prefer. Currently this is Singapore (SG) or Japan (JA). -->

- Choose a **name** for your Bybit account, it can be whatever you want it to be

- Select the color you would like the API to be inside the terminal.

<!-- - Choose your Encryption Password. Remember to save this somewhere! You will need to input this password when you navigate back to the trade page of the trading terminal. -->

- Paste the **API Key** provided by Bybit here.

- Paste the **API Secret** provided by Bybit here.

- Click **‘Done’**

## Unified Margin trading

Unified Margin support has recently been introduced and there are a few things that are important to take note of:

<div class="text--center">
    <img src={InverseDerivs} alt="Inverse Derivatives account" style={{ width: 550 }} />
</div>

- Inverse contracts use the separate Inverse Derivatives wallet and are available through the Bybit Inverse setup mode in Tealstreet. Make sure that wallet is funded before trading inverse markets.

- Users will be unable to switch to isolated margin if they have a negative USDT balance.

:::note
If you do not wish to use a Unified Margin account you can create a sub-account as a workaround. They default to non Unified Margin.
:::

:::warning
As of Oct-2024 TealstreetV3 does not currently support isolated trading on Unified Margin accounts. V2 might still work.
:::

## Troubleshooting

:::warning
On May-8-2023 Bybit mandated KYC for all users, and shortly before that it started banning US IP addresses. If you are trying to trade from a restricted country or did not do the KYC you will not be permitted to execute orders even if you previously were able to.
:::

:::note
In March 2024 Bybit phased out support for Perpetual Futures for users in the Netherlands due to regulatory reasons.
You can find more [info here](https://announcements.bybit.com/article/introducing-bybit-netherlands-bybit-nl-platform-blt32bff64c58963ac7/).
:::

### Why am I getting an error about unmatched IP when trying to use testnet? I used the system generated option

- Testnets are generally provided on a best-effort basis and are not guaranteed to work.

### I have a Unified Trading Account and I moved my funds into it, API Linked successfully but I can't execute orders and Tealstreet shows I have zero margin? whats going on?

- You might be on Isolated, Try switching to _Cross_ Margin. Tealstreet does not currently support _Isolated_ on Unified Margin accounts.

### I'm getting an error about illegal category why is that?

- Double-check that the account mode you connected matches the market you are trading. For inverse perps, use the Bybit Inverse setup mode and fund the Inverse Derivatives wallet.

### Does Tealstreet support Bybit Demo mode?

- Yes, Tealstreet V3 supports demo mode. Make sure you are using demo and not testnet. You also do not need to provide any IP's for the whitelisting process for demo mode.

### Does Tealstreet support HyroTrader?

- Yes, Tealstreet supports HyroTrader. You can connect your HyroTrader account to Tealstreet by following the [HyroTrader Instructions](https://www.hyrotrader.com/faq/getting-started/) and connecting a `Bybit Demo` account.

### I have available balance but my available margin is zero and I can't place orders?

- Try toggling your isolated / cross margin settings on the official Bybit website. Some users have reported that this resolves the issue.

### I get an error about signing an agreement before being able to trade?

<div class="text--center">
    <img src={DocumentSign} alt="Document Sign" style={{ width: 550 }} />
</div>

- Bybit requires you to sign a disclosure document to trade certain products. If you go to their website and manually trade the product in question, you will get a popup to sign the agreement. (HyroTrader users may need wait a few minutes & reload Tealstreet to get around this.)
