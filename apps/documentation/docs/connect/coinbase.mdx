## Connecting [Coinbase](https://www.coinbase.com/) to Tealstreet

- First, make sure you are logged into your [Coinbase](https://www.coinbase.com/) account.

<!-- :::note
Consider supporting Tealstreet by using the referral _[link](https://www.coinbase.com/)._
::: -->

<IntroTealstreet exchangeName="Coinbase" />

Keep this window open, it will be used later after we create the API Key on the Coinbase site. \* In particular we'll be using the IP's shown in the Tealstreet window to whitelist the API Key in Coinbase later.

---

### Enabling Futures Trading on Coinbase

Now lets bring up the coinbase account and make sure Advanced Trading is enabled.

<div class="text--center">
    <img src={coinbaseToggleAdv} alt="Advanced Trading Toggle" style={{ width: 550 }} />
</div>

If you haven't yet done so you will need to unlock Futures on your account by clicking the button shown below.

- This will require you to agree to the terms and conditions for futures trading as well as perform any identify verification checks Coinbase may deem necessary.

<div class="text--center">
    <img src={coinbaseUnlockfuts} alt="Unlock Futures" style={{ width: 750 }} />
</div>

---

### Creating the API Key

Next open your Coinbase settings page and goto the **API** page.

<div class="text--center">
    <img src={coinbaseApiSettings} alt="API Settings" style={{ width: 550 }} />
</div>

Use the Coinbase recommended method to make your Developer Platform API Key.

- Legacy API keys have been deprecated and might not work in the future.

<div class="text--center">
    <img src={coinbaseApiCreate1} alt="Create API Key Developer Platform" style={{ width: 550 }} />
</div>

Click **Create API Key**

<div class="text--center">
    <img src={coinbaseApiCreate2} alt="Create API Key Developer Platform" style={{ width: 550 }} />
</div>

Now fill out the information requested for the API Key. - _**Name**_: This can be whatever you want to call the key. - _**API Whitelist**_: Enter the IP Addresses that are shown inside the Tealstreet API Key creation window we loaded up earlier. - Select the _**View & Trade**_ permissions. You might need to change the portfolio setting to something other then Defaul to edit the permissions. - Select the _**Create & Download**_ button when done.

<div class="text--center">
    <img src={coinbaseApiCreate3} alt="Create API Key Developer Platform" style={{ width: 550 }} />
</div>

:::caution
Do not activate transfer permission on this API Key.
:::

Proceed to confirm your keys details, and store them securely. Once you have the information you need return to the Tealstreet window we left open earlier.

---

<div class="text--center">

Fill out the information you got from Coinbase to link the API Key inside Tealstreet

## Troubleshooting Coinbase

Below is a list of reported issues or concerns for **Coinbase**.

### I am getting an error "No INTX Portfolio" ?

Coinbase does not offer perpetual futures trading in all regions. If you are in a region that does not support perpetual futures trading, you will see this error. \* Dated Futures are separate from Perpetual Futures and are not supported by Tealstreet at this time.

![Coinbase-RegionRestricted](/img/connect/coinbase/coinbase-intx-error.png)
