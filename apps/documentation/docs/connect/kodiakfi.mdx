## Connecting [KodiakFI](https://teal.link/kodiak) to Tealstreet

<IntroTealstreet exchangeName="KodiakFI" />

---

### Creating the key

- Now we are ready to generate the API Key. Head on over to [KodiakFI](https://teal.link/kodiak) and:
  - Connect your wallet.

<!-- :::::note
You will not be able to connect to KodiakFI if you are connecting from a geo-restricted region.
::::: -->

<div class="text--center">
    <img src={WalletConnect} alt="Wallet Connect" style={{ width: 500 }} />
</div>

- Select the wallet you want to use for the API Key.

<div class="text--center">
    <img src={WalletConnect2} alt="Wallet Connect 2" style={{ width: 400 }} />
</div>

<!-- ::::caution
KodiakFi requires you to deposit funds before you can create an API Key. So make sure you take care of that first by using their **Deposit** button at the top right of the page after you have signed in with your wallet.
:::: -->

- Once you are connected to your wallet, navigate to the API Key page by clicking the **Portfolio** button at the top and choosing **API Keys** from the side menu.

<div class="text--center">
    <img src={ApiDropdown} alt="API Management" style={{ width: 250 }} />
</div>

:::::note
KodiakFI requires you to 'Create an Account' before you can create an API Key. You will also need to 'Enable Trading' before you can can finish creating an account.
:::::

- Create your account if you haven't already. It will also enabling trading during the process.
- After you have created your account and enabled trading you will then need to create the API Key.
  - Click the **Create API Key** button to begin the process.

<div class="text--center">
    <img src={CreateApi} alt="CreateApi" style={{ width: 400 }} />
</div>

- At the time of this writing you can leave the IP Whitelist option empty.
- Ensure 'Read' and 'Trading' are selected for the permissions.
  - Click 'Confirm' to continue and sign the transaction with your wallet.

<div class="text--center">
    <img src={CreateApi2} alt="Create API Finished" style={{ width: 400 }} />
</div>

- Securely store the API Key information.
- When done click the **OK** button.

- Now lets return to Tealstreet to resume the API Linking process now that we have the 3 pieces of information we need.

---

### Connecting the key to Tealstreet

Now let us proceed back to where we left the Tealstreet API page:

<div class="text--center">
    <img src={ApiTeal} alt="Api Creation2" style={{ width: 600 }} />
</div>

- Proceed to fill out the form with the information you got when you created the API on the KodiakFI API page.
  - Give the key a name, this can be anything you want.
  - Choose the color you want your API to be in the terminal.
  - Provide the **Account ID** KodiakFI showed you when you created the API Key.
  - Provide the **API Key** KodiakFI created when you created the API Key.
  - Provide the **API Secret** KodiakFI showed you when you created the API Key.
  - Click done.
