## Mac Desktop

<div class="text--center">

![Apple](/img/client/apple.png)

</div>

This page will go through the download and installation of the Tealstreet Desktop Client.

- Head to the Tealstreet download [page](https://www.tealstreet.io/download/) to download the desktop client.

<!-- - If you have an Apple Silicon Mac (**M-series**), choose the Apple Silicon build.

- If you have an **Intel** Mac, choose the Intel/macOS build. -->

<div class="text--center">

![Download-MacOS](/img/client/Mac/downloadmac.png)

</div>

:::note
Or you can use [Tealstreet in your browser](https://app.tealstreet.io/trade)
:::

Depending on your macOS/Gatekeeper settings, you may see a security prompt on first launch.  
If prompted, open **System Settings -> Privacy & Security** and use **Open Anyway** for Tealstreet listed in the **Security** section.

You usually only need to do this once per downloaded build.

## Security

If your macOS Gatekeeper settings are set to block non-app store applications, you may see this security prompt.

<div class="text--center">

![Download-MacOS](/img/client/Mac/v3/security.png)

</div>

You can go into your system settings, under the **Security & Privacy** section there should be a section called *Security* where you can see the list of applications blocked from running

<div class="text--center">

![Download-MacOS](/img/client/Mac/v3/privacy-settings.png)

</div>

Click the **Open Anyway** button to allow Tealstreet to run.

<div class="text--center">

![Download-MacOS](/img/client/Mac/v3/security-settings.png)

</div>
