## Windows Desktop

<div class="text--center">

![Windows](/img/client/Windows/windows.png)

</div>

This page will go through the download and installation of the Tealstreet Desktop Client.

- Head over to the Tealstreet [download page](https://www.tealstreet.io/download/) to download the desktop client.

- Select the "Download for Windows" Option to automatically start your download

<div class="text--center">

![Download-Windows](/img/client/Windows/download-windows.png)

</div>

- The file "TealstreetV3-Setup-X.X.X.exe" will download on your Windows machine.

<div class="text--center">

![Setup](/img/client/Windows/setup-windows.png)

</div>

:::note
`X.X.X` represents the current desktop version.
:::

- Double click the file to begin the installation process.

---

### Windows UAC Security

- You may see the following SmartScreen/UAC popup on first launch:

<div class="text--center">

![Popup](/img/client/Windows/moreinfo.png)

</div>

If this appears, click **More info** and then **Run anyway** to continue.

<div class="text--center">

![Run-Anyway](/img/client/Windows/runanyway.png)

</div>

- This starts setup and installs the Tealstreet desktop client. When installation completes, you will see the Tealstreet login window.

<div class="text--center">

![Tealstreet-Desktop](/img/client/Windows/tealstreetdesktop.png)

</div>

- Go ahead and sign in with your Tealstreet account or create a new account if you don't have one yet.

## Notes & Tips

:::note
The Tealstreet desktop client will be installed at the following location on your machine:
![windowspath](/img/client/Windows/winfilepath.png)
:::

:::tip
Having trouble locating the installation folders? Make sure you have enabled hidden folders which are hidden by default on Windows.
Read more in this guide to [access hidden folders on Windows](https://help.ableton.com/hc/en-us/articles/209070509-How-to-access-hidden-folders)
:::

:::tip
You can **Pin** the Tealstreet Desktop Client to your taskbar by right clicking and selecting "Pin to Taskbar"

![Tealstreet-Pin](/img/client/Windows/pin.png)
:::

![Tealstreet-Zoom](/img/client/ClientZoom.png)

:::tip
You can **Zoom** the Tealstreet window in and out by clicking the zoom buttons:

You can also use the keyboard shortcut **Ctrl +** to achieve the same effect.
:::

## Troubleshooting Windows

### I am using Windows 7 and I get an error about 'GetPackageFamilyName' in Kernel32.dll whats happening?

    * In 2023 Chromium discontinued support for Windows 7. This means that the Tealstreet Desktop Client will not work on Windows 7. We recommend upgrading to Windows 10/11 or using the Web Client. You can read more about it [here](https://www.electronjs.org/blog/windows-7-to-8-1-deprecation-notice)
