### Trading on the Chart

You can use the Tealstreet chart to:

- View Positions
- Place Orders
- Drag Orders
- Remove Orders
- Place Stop Orders
- Place Scaled Orders
- View your liquidation
- Veiw your break-even price
- View your fills

<div class="text--center">

![Chart-Trading](/img/trading/chart-trading.gif)

</div>

:::note
The Tealstreet Chart will remember the settings in your **Place Order** window to interact with the chart. This includes settings like post, reduce, trigger price, and close on trigger.

## Multiple Chart Trading

You can use the Tealstreet terminal to have multiple Trading View charts to view and manage your positions across multiple trading pairs.

<div class="text--center">

![Add-Chart](/img/trading/chart-trading/v3/add-chart.gif)

</div>

- Click on the "+" button at the top of a module window
    - Choose the 'Chart' module
- Drag the new chart component to a desired location in the terminal

<div class="text--center">

![Add-Chart-2](/img/trading/chart-trading/v3/adding-multiple-charts.gif)

</div>

- Alternatively you can click the tile button at the top right of the terminal near the options and theme editor to add new chart modules

### Multiple Chart Syncing

Once you have added your charts and positioned them as you want, you then need to sync them to their respective api key(s)

- Right click the header and choose the 'Select Market' option to sync the chart to the desired api key & ticker

<div class="text--center">

![Multi-Chart-Sync](/img/trading/chart-trading/v3/linking-chart-multi-charts.png)

</div>

If you made a mistake and linked it to the wrong api, you can click this dropdown and choose a different one or click x to remove one

<div class="text--center">

![Multi-Chart-Sync-Settings](/img/trading/chart-trading/v3/linked-keys-multi-charts.png)

</div>

If you want your Place Order module focus on the chart you clicked last:

- Access the chart settings cogwheel and enable the **Sync Symbol on Click** setting

<div class="text--center">

![Multi-Chart-Sync-Settings-2](/img/trading/chart-trading/v3/multi-charts-sync.png)

</div>

Once you have linked your chart windows to their respective API Keys you will be able to trade between the windows quite easily!

## Pine Script Editing

When your chart is running on Tealchart, Tealstreet shows a live Pine editor below the chart. This editor lets you write simple chart studies directly in the terminal and see them applied to the current chart after a short pause.

You can use the editor to:

- Create overlays with `indicator("Name", overlay=true)`.
- Create separate-pane indicators with `overlay=false`.
- Add editable settings with inputs such as `input.int`, `input.float`, and `input.color`.
- Read chart series such as `open`, `high`, `low`, `close`, and `volume`.
- Use common helpers from namespaces such as `ta`, `math`, `color`, `str`, `syminfo`, and `timeframe`.
- Draw output with `plot`, `plotshape`, `plotchar`, and `plotcandle`.

For example:

```pine
//@version=6
indicator("Live EMA", shorttitle="EMA", overlay=true)

length = input.int(20, "Length", minval=1)
lineColor = input.color(color.teal, "Line")

plot(ta.ema(close, length), title="EMA", color=lineColor, linewidth=2)
```

The editor toolbar shows whether the script is waiting for the chart, running, applied, or failing with an error. You can collapse the editor with the chevron button or drag the top handle to resize it. Your draft is saved locally, and the live study is stored as a local chart study so it can appear in the chart's **MY SCRIPTS** indicator category.

:::note
The live Pine editor is available on Tealchart. If your chart is using the TradingView engine, this bottom editor will not be shown.
:::

## Draggable TakeProfit & Stoploss

A very powerful feature while using Chart Trading in the Tealstreet Terminal is the ability to drag your TP & SL lines on the chart from your open positions.

### Partial TP/SL Draggables

- You can activate the partial draggable functionality by enabling the **Enable Partial TP/SL on Chart** setting in the **TradingView** settings category.

<div class="text--center">
    <img src={DraggablePartial} alt="Draggable Partial SL/TP" style={{ width: 550 }} />
</div>

- Once activated you can adjsust the size of the TP/SL based on where you drag it horizontally on the chart. The following gif shows an example of using this feature.

<div class="text--center">
    <img src={DraggablePartial2} alt="Draggable Partial SL/TP 2" style={{ width: 750 }} />
</div>

:::tip
You can also adjust how large your TP or SL will be by dragging the TP/SL order horizontally on the chart.
:::

:::caution
Not every exchange functions the same, for example **[Bitget](/docs/connect/bitget)** does not allow you to have more then one stoploss active at a time. This means that if you have a position open and you drag the stoploss to a new price it will cancel and fail if you have an existing stoploss.
:::

## One Click Trading

:::tip
Ensure _[hotkeys](/docs/trade/shortcuts)_ are enabled.

## Additional information

:::caution

- Stoplosses do not function identically across all exchanges
    - As an example on **[bitget](/docs/connect/bitget)** you will not be able to activate more then a single stoploss for an active position due to how the exchange handles stoplosses
    - Some exchanges and/or settings will allow stops to show as infinity, this functionality can be emulated with the **[Close-On-Trigger](/docs/trade/placing-orders#stop-orders)** setting for exchanges that do not do infinity stops
- It is usually a good idea to set the setting **Stops Placed on Chart Close on Trigger** as this will guarentee you do not accidentally end up an an opposite direct position when trying to close out of a position.
  :::
