Tealstreet trades through API keys from your exchange. There are three ways to get them onto your phone:

| Way                                         | Use it when                                                                  |
| ------------------------------------------- | ---------------------------------------------------------------------------- |
| [Cloud key sync](#cloud-key-sync)           | You already use Tealstreet on your computer. Your keys appear on their own.  |
| [Scan a QR code](#scan-a-qr-code)           | You want one account from your computer, without turning on cloud sync.      |
| [Enter a key by hand](#enter-a-key-by-hand) | You're new, or the key isn't in Tealstreet yet.                              |

:::warning Sign in first
Sign in on the phone before you add a key (see [Getting started](./getting-started.mdx#2-sign-in)). Keys are saved
to your Tealstreet account.
:::

## Cloud key sync

Cloud sync keeps the same API keys on every device you sign in on. Your keys are encrypted on your device with a
**cloud sync password** before they're stored, and Tealstreet never sees that password.

:::info Turn it on first
Cloud sync must be on for your account: in the Tealstreet web app, open **Settings → Accounts** and turn on **Cloud
sync for API keys**. It's one setting for your whole account. Each device then asks for your cloud sync password once.
:::

secret.

For step-by-step help on a particular exchange, see the [Connect](/docs/connect/api-general) guides.

## Editing or removing an account

Open **Settings → Accounts** (side panel → **API keys**). Tap an account's row to change its name, keys and options.
**Delete Account** at the bottom of its form removes it from Tealstreet after you confirm; the key stays valid on the
exchange until you delete it there.

## Troubleshooting

### The key was saved but won't connect ("Error validating…")

- **"The account is not connected because its API key was not accepted. Check the … Tealstreet IP addresses and key
  permissions"**: the key has an IP whitelist. Tick **Use Tealstreet IPs** and add those IPs to the key on your
  exchange.
- **"Couldn't read this account's balance. Check the API key permissions and try again."**: the key needs read and
  trade permissions.
- **"Couldn't reach Tealstreet's servers…"** or **"The exchange took too long…"**: a connection problem. Try again
  in a moment.
- **"Please input your …"**: a required field is empty.

### "Couldn't unlock cloud sync"

Check the password and your connection, then try again. The cloud sync password is not your Tealstreet login
password. If you've lost it, use **Reset cloud sync** on a device that's still unlocked.

### "Invalid QR Code" or "Invalid JSON format"

The scan failed, or the code isn't a Tealstreet account code. In the web app, open **QR Code Sync** again and scan
the code it shows.

### The camera won't open

If you see **"Camera access is required to scan QR codes."**, tap **Open Settings** and allow camera access for
Tealstreet, then try again.
