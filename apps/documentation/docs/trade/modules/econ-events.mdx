The **Economic Events module** helps you monitor upcoming macro releases, expected impact, and event timing while trading.

</div>

## Activating the Economic Events module

<div class="text--center">
    <img src={EconEventsSettings} alt="Econ Events Settings" style={{ width: 600 }} />
</div>

- Open **Trade Settings**.
- Go to the **Modules** tab.
- Enable **Economic Events**.

:::tip
Remember to unlock your layout to be able to move the module around.
:::

:::note
Event sources and available filters can vary by release.
:::
