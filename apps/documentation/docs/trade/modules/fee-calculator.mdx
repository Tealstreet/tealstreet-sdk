## Activating the Fee Calculator module

<div class="text--center">
    <img src={FeeCalc2} alt="Fee Calc Settings" style={{ width: 600 }} />
</div>

- Open **Trade Settings**.
- Go to the **Modules** tab.
- Enable **Fee Calculator**.

:::tip
Remember to unlock your layout to be able to move the module around.
:::
