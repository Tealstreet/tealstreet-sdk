The **Forex Calendar module** embeds an economic calendar view so you can monitor upcoming events while trading.

:::note
Module availability can vary by release and layout profile. If you do not see this module in the list, your current build/layout may not expose it.
:::

## Activating the Forex Calendar module

<div class="text--center">
    <img src={ForexCalendar} alt="Forex Calendar Settings" style={{ width: 400 }} />
</div>

- Open **Trade Settings**.
- Go to the **Modules** tab.
- Enable **Forex Calendar**.

:::tip
Remember to unlock your layout to be able to move the module around.
:::
