The **Ticker Data module** provides a compact snapshot of market statistics for the selected instrument.

<div class="text--center">
    <img src={TickerData} alt="Ticker Data Module" style={{ width: 400 }} />
</div>

Typical values shown include:

- Last price
- 24h change
- Volume
- Additional market-specific stats (when available)

## Activating the Ticker Data module

- Open **Trade Settings**.
- Go to the **Modules** tab.
- Enable **Ticker Data**.

:::tip
Remember to unlock your layout before repositioning module panels.
:::

:::note
Exact fields can vary by exchange and release.
:::
