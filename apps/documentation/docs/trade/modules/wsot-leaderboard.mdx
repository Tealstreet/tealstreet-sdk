## Activating the WSOT Leaderboard module

- Open **Trade Settings**.
- Go to the **Modules** tab.
- Enable **WSOT Leaderboard**.

<div class="text--center">
    <img src={WSOTLeaderboardModule} alt="WSOT Leaderboard Module" style={{ width: 350 }} />
</div>

The WSOT Leaderboard will show the following information:

- Rank
- Username
- PnL
- Volume

:::tip
Use the button in the lower-right of the module to show more than 10 ranks.
:::

:::note
Leaderboard availability depends on whether an active WSOT season is supported in the current build.
:::
