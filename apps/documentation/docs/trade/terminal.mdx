## Primary Trade Settings

In the top right corner of the main trading window you will find the Primary Trade Settings for Tealstreet.

<div class="text--center">
    <img src={SettingsButton} alt="Settings" style={{ width: 500 }} />
</div>

Here you can change various settings for the terminal. Such as draggable orders, Risk management tools, Hotkeys, and more.

<div class="text--center">
    <img src={TerminalSettings} alt="Settings" style={{ width: 700 }} />
</div>

---

### Market/Trading Pair

To change the 'Market' / 'Trading Pair' click the drop down at the top of the terminal with an active API selected. The primary market your API key is connected to will appear in the center. You can select your favorite pair from this drop down.

:::tip
Click on the star next to the pair to favorite it. Any favorites will appear in the favorites column.
:::

<div class="text--center">
    <img src={Market} alt="Market" style={{ width: 500 }} />
</div>

You can view other markets if you have other API's connected. The dropdown contains a filter which will let you add or remove other exchanges from the list.

:::note
You will not be able to trade the pair unless you have the API key for that exchanges added to Tealstreet.
:::

---

### API Key Selection

At the top of the terminal you can see the currently active API's and can switch between them. If you have not added an API key this menu may be blank. If you have only one API key connected you will only see one option.

<div class="text--center">
    <img src={API} alt="API" style={{ width: 800 }} />
</div>

:::tip
Click on the star next to the API key to favorite it. Any favorites will appear on the favorites bar for easy switching between API keys.
:::

---

### Sound Settings

Tealstreet offers sound effects for different actions across the main trading window. To change the volume level, click the speaker icon and use the slider to find your preferred audio level. Click on the icon to mute all sounds.

<div class="text--center">
    <img src={Sound} alt="Sound" style={{ width: 600 }} />
</div>

---

### Lock/Unlock Button

You can adjust all the modules and windows within the layout of Tealstreet. You can adjust their size and position. To prevent accidentally moving or changing a window, simply click the 'Lock' button. When the lock icon appears closed, your window settings are locked in place. When the lock icon appears open, your windows settings can be adjusted.

<div class="text--center">
    <img src={Lock} alt="Lock" style={{ width: 650 }} />
</div>

### Profiles (Formerly Workspaces)

Inside your settings is the profiles category. A profile is a collection of settings and windows that you can save and load at any time. This allows you to have different profiles for different trading strategies, environments, or exchanges.

<div class="text--center">
    <img src={Profiles} alt="Profiles" style={{ width: 800 }} />
</div>

- Here you can modify existing profiles in this window
    - You can import an external profile (such as from discord or a friend)
    - You can duplicate the specified profile
    - You can delete the specified profile
    - You can export the specified profile to save it to disk or share it with others

:::note
new profiles may occasionally be randomly generated by Tealstreet. (Such as when introducing a new feature or module)
:::
