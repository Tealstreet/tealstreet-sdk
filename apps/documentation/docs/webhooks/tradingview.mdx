A TradingView alert can run Tealstreet CLI commands — on the Tealstreet CLI or in a browser tab, whichever listener you choose.

1. Copy your webhook URL from **Settings → Webhooks**.
2. In TradingView, create an alert, tick **Webhook URL** and paste the URL.
3. In the alert's **Message**, write the commands to run:

   ```
   buy $250 SOLUSDT at -0.5%
   ```

4. Choose the listener that runs your alerts in **Settings → Webhooks** (or with `webhook claim` in the CLI).

:::note
TradingView requires 2FA on your account to use webhooks.
:::

Full details — the listener choice, what an alert may run, and the delivery log: [Webhooks](/docs/webhooks). For the CLI side: [Webhook from TradingView](/cli/recipes/webhook-from-tradingview).
