Webhooks let external services reach Tealstreet. A **TradingView** alert runs CLI commands — on the Tealstreet CLI or in a browser tab, whichever listener you choose. **Arkham Intelligence** alerts are received into Tealstreet.

## Creating a webhook

- To begin click the settings cogwheel at the top right of the terminal

    <img src={WebHooks1} alt="Web Hooks 1" style={{ width: 750 }} />
</div>

- Then click the Webhook category in the settings window

<div class="text--center">
    <img src={WebHooks2} alt="Web Hooks 2" style={{ width: 750 }} />

In here you will be able to get the information necessary to link Tealstreet to other services. Such as TradingView or Arkham Intelligence.

### TradingView Webhooks

Tealstreet automatically generates a unique webhook URL for each user to receive TradingView alerts.

#### Setup Process

- **Get Your Webhook URL**: In the webhook settings, Tealstreet displays your unique webhook URL in the format:

    ```
    https://preview.tealstreet.io/api/webhooks/tv/{your-unique-hash}
    ```

- **Regenerate if Needed**: You can click the "Regenerate" button to create a new unique hash if needed for security purposes.

- **Configure TradingView Alert**: - Select and copy the entire webhook URL from Tealstreet - Switch to TradingView and place an alert on your chart - Go to the alert notification settings - Tick the "Webhook URL" box and paste the copied URL into the webhook field

:::note
TradingView requires you to enable 2FA authentication to use webhooks. You may get a popup asking you to enable 2FA when you try to save the webhook if you haven't enabled it yet.
:::

<div class="text--center">
    <img src={WebHooks3} alt="TradingView Webhook" style={{ width: 500 }} />
</div>

- **Save the Alert**: Click Save when done.

#### The alert message is CLI commands

Write the commands to run in the TradingView alert's **Message** box, exactly as you would type them in the CLI:

```
buy $250 SOLUSDT at -0.5%
close longs; buy $500 BTCUSDT
```

Chaining (`;` waits for the previous step, `&` runs alongside it), aliases and vars all work. The listener runs each alert on its **current account**; name the symbol in each order. Commands that change saved state or settings (`account`, `set`, `alias`, `simulation`, `fatfinger`, …) are refused — see the [CLI docs](/cli/operations/hooks-and-webhooks#what-a-webhook-may-not-run) for the full list.

#### Choose which listener runs your alerts

Exactly one listener runs your TradingView alerts — the Tealstreet CLI or a browser tab. You can run both, possibly on different accounts, so Tealstreet never switches between them for you. In **Settings → Webhooks**:

- **Receive webhooks in this browser** makes this browser a listener you can choose. It is off by default, and only one tab of the browser listens.
- **Listeners** shows each CLI and browser that has connected, whether it is online, and its accounts. **Make this the listener** moves your alerts to it.
- **Wait for an offline listener** sets how long an alert waits for the chosen listener to come back. After that it **expires without running** — it is never sent to a different listener.
- **Recent alerts** shows each alert, its status (done, failed, expired) and its output.

No listener runs your alerts until you choose one — not even the first that connects — because a TradingView URL set up before this feature may still be posting.

#### Security

- **The webhook URL is a password.** Anyone who has it can trade on the chosen listener's accounts. Regenerate it if it leaks; the old URL stops working.
- **Each alert runs at most once**, even across reconnects.
- At most 60 alerts per minute are accepted.

### Arkham Intelligence Webhooks

Tealstreet supports receiving alerts from Arkham Intelligence through their webhook system.

#### Setup Process

- **Get Your Webhook URL**: In the webhook settings, Tealstreet provides the receiving URL:

```
https://preview.tealstreet.io/api/webhooks/arkham
```

- **Configure Arkham Intelligence**: - Login to your Arkham Intelligence account and navigate to the [Alerts Page](https://intel.arkm.com/alerts/all) - Edit or create an existing Alert - At the bottom, choose how you wish to be alerted and select "Webhook"

<div class="text--center">
    <img src={WebHooks4} alt="Arkham Intel Webhook" style={{ width: 800 }} />
</div>

- **Configure the Webhook**: - A window will popup with configuration options - **Header Code**: Save the header code (found after the semicolon in `Arkham-Webhook-Token: your-key-here`) - **Webhook URL**: Paste the Tealstreet receiving URL into Arkham's text input box

<div class="text--center">
    <img src={WebHooks5} alt="Arkham Intel Webhook 2" style={{ width: 800 }} />
</div>

- **Save Your Header Key in Tealstreet**: - Copy the header code from Arkham - Paste it into the "Webhook Key" field in Tealstreet's webhook settings - If you have multiple alerts, separate the keys with commas - Example: `OU00c0s0hn056V,pFUpi00tcu0lcT,cd1D000Xvllfbz` - Click "Save Arkham Webhook Key"

- **Complete Setup**: Click "Connect" in Arkham and save the alert

#### How It Works

- **Authentication**: Arkham sends alerts with a header `arkham-webhook-token` containing your unique key
- **Multiple Alerts**: You can configure multiple Arkham alerts by separating their keys with commas
- **Data Storage**: Alerts are stored in the `arkham_log` table in Tealstreet's database
- **Real-time Display**: Arkham alerts appear as notifications in your terminal interface
- **Security**: Only alerts with valid header tokens are processed and displayed

## Security Features

- **Unique Identifiers**: Each user has their own unique webhook URLs and authentication keys
- **Token Validation**: All incoming webhook requests are validated against stored user credentials
- **Regeneration**: Webhook URLs can be regenerated for enhanced security
- **Isolation**: Users can only receive alerts intended for their account

## Troubleshooting

- **TradingView 2FA**: Ensure 2FA is enabled on your TradingView account
- **Invalid Requests**: Check that you're using the correct webhook URL and authentication tokens
- **An alert did not run**: open Settings → Webhooks → Recent alerts. *Expired* means it did not run: no listener was chosen, the chosen listener was offline past the wait time, or you moved the listener before it ran; *failed* shows the error.
- **Multiple Alerts**: For Arkham, ensure multiple keys are separated by commas without spaces
