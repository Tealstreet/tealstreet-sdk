### Tealstreet 是免费的吗？

Tealstreet 是免费使用的。我们通过与交易所的交易赚钱。这不会给您带来额外的费用，因为它类似于推荐链接。这是所有加密货币交易终端的工作方式，尽管许多终端除此之外还向用户收取每月费用。在 Tealstreet，我们相信如果我们为我们的交易者提供良好的免费交易工具，那么我们将通过共享用户和 Tealstreet 的增长而共同获得回报，而无需向我们的用户收取任何额外费用。这是一个正反馈循环。![Okayge](/img/social/okayge.png)

### 我能相信 Tealstreet 吗？

Tealstreet 团队在安全方面做了很多工作。安全是终端开发的第一个方面，也是第一要务。安全方面由 AWS 托管。用户信息，如 API 密钥，在放入数据库之前会被加密。AWS 管理主密钥。如果有人黑客入侵 Tealstreet，他们将无法获得您的主 API 密钥。此外，第二层安全性以 [端到端 API 用户加密](/docs/connect/api-encryption) 的形式添加。Tealstreet 团队认为，终端的安全性与其他加密服务一样好，甚至更好。在使用 Tealstreet 之前，请务必阅读服务条款。

:::tip
请务必阅读 _[API 指南](/docs/connect/api-general)!_
:::

### 我在下载更新时遇到了一个错误，它提到了 objects.githubusercontent.com？

这是 Github 在其端上执行的操作，如果下载时间过长，它会过期内部下载会话，从而导致此错误弹出。这基本上意味着下载时间太长或速度太慢。建议您关闭弹出窗口、关闭 Tealstreet 并关闭任何可能存在的下载或流，然后重新启动 Tealstreet 并重试。

- 您也可以转到 [下载](https://www.tealstreet.io/#download) 页面，手动下载最新版本。

#### 我正试图将 api 链接到 Bybit Testnet，但一直收到关于 IP 地址未绑定的错误信息？

测试网是尽力支持的。它们可能无法正常工作，也可能突然中断。

由于使用的人很少，我们目前优先支持实时市场。如果您正在使用测试网，但它出现故障，请告诉我们，我们会尽力修复。

#### 我遇到一个错误，终端不断尝试重新连接，而且所有指示点都显示为绿色？

有些用户报告说，重新同步设备上的时间后，问题就解决了。如果您使用的是 Windows 系统，可以右键单击右下角的时间，然后选择 "调整日期/时间"。然后点击 "立即同步"。
