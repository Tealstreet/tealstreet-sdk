Tealstreet.io交易终端现在支持Web端和桌面端软件的双因素认证（2FA），强烈建议用户使用2FA来获得最佳安全性。

## 设置双因素认证

- 在我们介绍如何将双因素认证添加到您的Tealstreet帐户之前，您需要一个2FA应用程序。如果您已经有一个，可以跳过第1步。

- 如果没有，则需要在移动设备或平板电脑上下载双因素认证器应用程序。Tealstreet推荐使用Google Authenticator应用程序。

- 转到[Tealstreet](https://app.tealstreet.io)并登录您的帐户。

:::note
如果您没有帐户，只需单击标有“注册”的绿色按钮即可。
:::

- 接下来，单击终端顶部右侧的用户图标。

<div class="text--center">

![2FA设置步骤1](/img/connect/2fa/2fastep1.png)

</div>

- 然后单击设置以进入设置页面。

<div class="text--center">

![2FA设置步骤2](/img/connect/2fa/2fastep2.png)

</div>

- 然后单击API密钥下的“安全性”。

<div class="text--center">

![2FA设置步骤2](/img/connect/2fa/settings.png)

</div>

- 然后，您将看到与您的帐户关联的电子邮件地址和启用双因素认证的蓝色按钮。单击“启用”并继续下一步。

<div class="text--center">

![2FA设置步骤3](/img/connect/2fa/2fastep3.png)

</div>

- 接下来，您将看到一个带有QR码图像的弹出窗口。
    1. 使用2FA应用程序扫描QR码。
    2. 输入应用程序中的六位数字。
    3. 确认您的2FA。单击“确定”并移至下一步。

<div class="text--center">

![2FA设置步骤4](/img/connect/2fa/2fastep4.png)

</div>

:::tip
我们建议在确保安全的地方备份您的QR码副本，以防您无法访问设备. **永远不要**与任何人分享您的QR码！Tealstreet员工将**永远不会**要求您提供2FA代码。
:::

- 输入2FA代码并收到确认后，您需要登出Tealstreet帐户。在此后的登录过程中，您都需要输入2FA代码。

:::tip
想要在2FA应用程序中重命名您的Tealstreet帐户吗？单击2FA应用程序顶部右侧的三个分组点或铅笔，然后按“编辑”。这将允许您将昵称更改为类似于“Tealstreet 2FA”的内容。
:::

### 如果我忘记或无法访问我的2FA会发生什么？

如果您无法访问2FA设备并且没有备份副本，则需要登出帐户并单击标有“忘记2FA”的按钮。按照重置2FA并添加新代码的步骤进行操作。。

![2FA恢复](/img/connect/2fa/2FA-Recovery.png)

</div>
