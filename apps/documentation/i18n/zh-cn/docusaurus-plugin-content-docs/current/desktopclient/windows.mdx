## 桌面客户端 - Windows

<div class="text--center">

![Windows](/img/client/Windows/windows.png)

</div>

本页面将介绍如何下载和安装Tealstreet桌面客户端。

- 前往 Tealstreet 下载[页面](https://www.tealstreet.io/download/) 下载 Tealstreet 桌面客户端。

- 选择“下载Windows版”选项以自动开始下载。

<div class="text--center">

![Download-Windows](/img/client/Windows/download-windows.png)

</div>

- 文件 "Tealstreet-Setup-X.X.X.exe" 将会下载到您的Windows电脑上。

<div class="text--center">

![Setup](/img/client/Windows/setup-windows.png)

</div>

:::note
X.X.X 代表当前客户端的版本
:::

- 双击该文件以开始安装过程。

---

### Windows UAC 安全

- 您将会看到以下弹窗

<div class="text--center">

![Popup](/img/client/Windows/moreinfo.png)

</div>

不要惊慌，我们正在努力让桌面客户端获得Windows签名。在此期间，单击“更多信息”按钮，然后选择“仍要运行”

<div class="text--center">

![Run-Anyway](/img/client/Windows/runanyway.png)

</div>

- 这将启动设置过程并在您的Windows计算机上安装Tealstreet桌面客户端。安装过程完成后，您将看到Tealstreet登录窗口。

<div class="text--center">

![Tealstreet-Desktop](/img/client/Windows/tealstreetdesktop.png)

</div>

## Notes & Tips

:::note
Tealstreet桌面客户端将安装在你机器的以下位置：
![windowspath](/img/client/Windows/winfilepath.png)
:::

:::tip
在查找安装文件夹时遇到困难？请确保您已启用隐藏文件夹，该文件夹在 Windows 默认情况下是隐藏的。
阅读更多 **[here](https://help.ableton.com/hc/en-us/articles/209070509-How-to-access-hidden-folders)**

:::tip
你可以**钉** Tealstreet桌面客户端到你的任务栏，方法是点击右键并选择 “钉到任务栏”。

![Tealstreet-Pin](/img/client/Windows/pin.png)
:::

![Tealstreet-Zoom](/img/client/ClientZoom.png)

通过点击缩放按钮，你可以**缩放** Tealstreet 窗口：

你也可以使用键盘快捷键 **Ctrl +** 来达到同样的效果。
:::

## Windows 故障排除

### 我使用的是 Windows 7 操作系统，在 Kernel32.dll 中出现了有关 “GetPackageFamilyName ”的错误，这是怎么回事？

    * 2023年，Chromium停止了对Windows 7的支持。这意味着Tealstreet桌面客户端将无法在Windows 7上运行。我们建议升级到Windows 10或使用Web客户端。你可以在[这里]（https://www.electronjs.org/blog/windows-7-to-8-1-deprecation-notice）阅读更多相关信息。
