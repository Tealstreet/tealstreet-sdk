## 其他Beta功能

这些是我们拥有的一些Beta系统，它们不是特定位于设置面板的Beta选项卡中。

### TWAP订单

在下单模块中，如果您选中右上角的复选框，则可以推出一些其他功能之一是TWAP。

TWAP是一种强大的工具，可用于帮助您平均持仓或减仓。在此窗口中，您可以调整要购买的大小，可以像通常放置订单一样指定大小，例如使用预设大小按钮，手动输入大小或使用保证金滑块。

<div class="text--center">
    <img src={TWAP} alt="TWAP Orders" style={{ width: 400 }} />
</div>

将此更改为正常订单系统的更改为：

- **订单计数**：
    - 这是您要TWAP执行的总订单数。如果设置为10，则会在激活后放置10个订单。
- **分钟**：
    - 每个订单之间的分钟数。如果设置了10个订单并将分钟设置为1，则会在10分钟内执行10个订单。
- **Rand. %**：
    - 在您的订单中引入随机性。这将通过您指定的随机量来变化您的订单计数，大小和订单之间的时间，这可以帮助您避免对监视订单簿的任何人太可预测。
        - 小心设置随机性太高，100％的值理论上可能不会放置任何订单，因为这在100％随机性的范围内。

:::note
即使刷新浏览器，TWAP会话也会被保留。
:::

### 停止TWAP订单

启动TWAP订单后，您可以转到“打开头寸和订单”面板来监视它并控制它。

<div class="text--center">
    <img src={TwapStop} alt="Stop TWAP Orders" style={{ width: 800 }} />
</div>

:::note
目前，TWAP仅支持**市场** / **Taker**订单。我们正在努力添加对**限价** / **Maker**追踪订单的支持。
:::

:::caution
TWAP是一项实验性功能，可能无法按预期工作。虽然我们会尽力使其稳定，但可能会出现问题。如果您遇到任何您认为是错误的问题，请联系我们的**[Discord](/docs/support/contact-us)**。
:::

:::danger
并非每个交易所的行为都相同。它们在API数据，延迟甚至速率限制等方面都有轻微差异。这使得很难将此功能的行为统一在每个交易所上。在使用它进行实时和全尺寸交易之前，请通过测试订单数量或twap执行的持续时间来小心使用。
:::
