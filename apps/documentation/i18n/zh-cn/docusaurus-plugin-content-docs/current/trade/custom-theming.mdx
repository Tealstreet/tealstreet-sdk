## 自定义主题

Tealstreet 的一个新功能是能够自定义几乎所有你在终端上看到的颜色。

<div class="text--center">
    <img src={ThemingButton} alt="ThemingButton" style={{ width: 1000 }} />
</div>

- 单击终端右上角的调色板按钮以打开主题菜单。

---

### 自定义您的主题

<div class="text--center">
    <img src={ThemeSettings} alt="ThemeSettings" style={{ width: 300 }} />
</div>

- 在您进行更改后记得保存。如果您希望与朋友分享布局或将其提交为我们 **[Discord](/docs/support/contact-us)** 中的社区礼物，您也可以导出。

:::tip
点击重置按钮以将主题恢复为默认设置。
:::

---

### 主题预设

<div class="text--center">
    <img src={ThemePresetDropdown} alt="ThemePresetDropdown" style={{ width: 600 }} />
</div>

- 使用滑动条在顶部切换由TS开发团队创建的预设或在下面切换社区创建的预设。

:::note
喜欢自己的主题并想分享吗？ 在我们的**[Discord](/docs/support/contact-us)**上联系我们，我们将把它添加到列表中！
:::
