# 深度图

这是 Teal Street 的深度图窗口。它以深度图的形式显示当前选定加密货币和选定的交易所/API 的买单和卖单。左侧显示买单，右侧显示卖单。

![深度图](/img/trading/depthchart.gif)

:::tip
使用鼠标滚轮可以调整价格范围。向前滚动滚轮会减小价差，就像缩小一样。向后滚动会增加价差，就像放大一样。
:::

### 查看

您可以通过选择不同的模式来更改深度图的外观。

![深度图-模式](/img/trading/depthchart-mode.gif)

- 单独
- 累积
- 组合

### 多个交易所

深度图的一个很好的功能是能够监视多个交易所。

![深度图-交易所](/img/trading/depthchart-exchange.gif)

:::note
如果您连接了 ByBit，请在二级市场下拉菜单中选择另一个交易所的 BTC 永续合约，以显示两个深度图的叠加。然后您将看到具有两个以上颜色的深度图。
::::

### 订单

只要您的订单在价格范围内，您的未成交订单也将显示在深度图上。订单在图表上用小黄圆圈表示。

![深度图-订单](/img/trading/depthchart-orders.gif)

### 图表悬停深度图

将鼠标光标悬停在 TradingView 图表上，将显示深度图叠加，以更好地比较价格和流动性。
