## 移动设备

Tealstreet支持在您的移动设备上进行交易。虽然正在开发原生的iOS和Android应用，但您仍然可以在外出时在移动设备上进行交易。

<div class="text--center">
    <img src={MobileGeneral} alt="Mobile General" style={{ width: 250 }} />
</div>

由于 Tealstreet 的设计，您在移动设备上将找到与桌面应用程序或浏览器上基本相同的功能。主要区别在于布局针对移动设备进行了优化。

您期望的所有工具都可以在移动设备上使用，以管理您的交易。

<div class="text--center">
    <img src={MobileGeneral2} alt="Mobile General2" style={{ width: 300 }} />
</div>

- 在这个截图中，请注意“锁定”机制，虽然与控制选项滚动条上模块大小调整的锁定机制类似，但此锁定是为了防止您在手机放在口袋或包中时意外更改交易或订单。

### 提升移动体验

<div class="text--center">
    <img src={MobileAddToHomeScreen} alt="Mobile Add To Homescreen" style={{ width: 250 }} />
</div>

当您首次使用移动版应用时，您可能会考虑使用“添加到主屏幕”选项，使其更像一个应用程序而不是网页浏览器。

它仍然在您的网页浏览器中运行，只是隐藏了一些可能不必要且占用屏幕空间的元素，例如浏览器导航选项和按钮。

### 常见问题

我不能在移动设备上调整模块的大小吗？

<div class="text--center">
    <img src={MobileOptionsScrollbar} alt="Mobile Options Scrollbar" style={{ width: 300 }} />
</div>

- 请注意，移动设备上可能难以看到滚动条。您可以滚动它们以查看额外的选项或功能。
    - 例如，在这个特定的截图中，您可以看到模块锁定机制，它将让您按照自己的意愿调整模块的大小。

---

我在移动设备上找不到我的API密钥？

- 与上一个问题和答案示例类似，您可能需要滚动选项栏才能看到API密钥选项。

---

我需要为移动设备专门创建一个API密钥吗？

- 不，您创建的API密钥并不特定于设备或浏览器。您可以在多个设备或浏览器上使用同一个API密钥。
