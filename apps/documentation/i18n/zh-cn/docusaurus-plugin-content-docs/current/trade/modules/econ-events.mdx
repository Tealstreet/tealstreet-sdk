### 启用经济事件模块

<div class="text--center">
    <img src={EconEventsSettings} alt="Econ Events Settings" style={{ width: 600 }} />
</div>

- 您可以在“交易设置”配置窗口的“模块”选项卡下启用“经济事件”模块。

:::tip
记得解锁您的布局，以便能够移动模块。
:::
