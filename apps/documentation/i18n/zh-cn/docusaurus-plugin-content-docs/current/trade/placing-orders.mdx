## 订单类型

在了解如何使用tealstreet的订单功能模块之前，有必要先来了解不同的订单类型：

---

### 市价单

市价单在下单后，立即执行当前订单簿的最优匹配价格。交易者无需设置特定的价格。虽然市价单能呗立即执行，但是不能保证执行价格，因为当前市场价格可能会快速波动。当交易者在价格快速变化的市场内开单或关单时，一般使用市价单。市价单的性质是“吃单”，因此手续费也最高。

---

### 限价单

市价单能让交易者设置一个订单价格，当价格到达设置的价格时执行，或者以更优的价格执行。

- 现价买单：设置的价格必须低于当前市场价。
- 现价卖单：设置的价格必须高于当前市场价。

当提交一个限价单时，如果订单簿中没有能与之很好匹配的订单，则该限价单进入订单簿中等待执行，同时增加了市场的深度。此外，限价单也能用来部分或完全关闭一个仓位。

:::caution
限价单的优点是能保证交易在特定的价格执行，但是如果使用Post模式，订单存在不一定被执行的风险。
:::

---

### 仅发布订单

仅发布订单严格确保限价单进入订单簿。当选中“Post”复选框，如果交易系统在下单的时候检测到该交易能立即被执行，则取消限价单。

当你在下现价单的时候同时选中“Post”选项，则该笔限价单交易进入交易所的订单簿。这意味着交易者能更好控制他们的交易手续费，尤其是对那些大额订单或者“剥头皮”交易者来说，能省下不少手续费。

:::note

:::

---

### 削减订单

削减订单通过动态减少或者调整你的仓位来减少你的仓位大小。这个功能确保你的仓位不会被意外的增大。

当选择“Reduce”选项后，交易者能确保接下来的订单操作是减仓，而不是新开一个反方向的订单，来防止当当前的仓位被关闭/止损或者清算后开出一个新的订单。

### 限价单

让我们先来学习如何利用Tealstreet提供的功能开一个限价单。

<div class="text--center">

![Place-Order](/img/trading/limit-order.png)

</div>

1. 蓝色高亮是当前激活的订单类型。

2. 这是你当前的仓位大小。你能通过币的数量来设置，也能通过对应USD的价值来设置。他们俩是关联的，你改变其中一个，另一个也会跟着改变。

3. 如果你选择“Track Delta”复选框，下单位置的价格将随着交易所价格的变动而变动。

4. 上面的输入框允许你调整订单价格的滑点。下面输入框的价格的设置将受上面delta设置的数字的影响。

5. 这个位置显示的数字是你在系统设置里面设置的快捷下单仓位大小。点击每个按钮能调整要下单的仓位大小，点击一个按钮两次，仓位翻倍。比如你点击了500两次，那你准备下单的仓位会变成1000。“CC”按钮会重置。这些快捷下单的数字能在选项里面调整，参考主要设置里面的[交易窗口](/docs/trade/terminal)设置。

:::note
点击蓝色或者红色大按钮后，才会正式下单。
:::

6. 如果你选择了“Post”选项，则你的订单会进入订单簿以限价单的形式被执行。使用这个功能有多个好处。能防止订单被立即执行，也能防止意外的市价单。这个功能也能帮助你节省手续费。

7. “Reduce”选项是用来减少你的仓位的。

- 如果你在开空并想部分平仓，在左侧选择“Reduce”然后下买单。订单执行后就会减少你的现有空单的仓位。
- 如果你在开多并想部分平仓，点击右侧的“Reduce”然后下卖单。订单执行后就会减少你现有多单的仓位。

8. 点击后执行你的订单。

### 快速订单

快速订单功能是用来针对特定的设置进行快速下单，在使用手机作为交易设备的时候非常有用。

<div class="text--center">

![Quick-Order](/img/trading/quick-order.gif)

</div>

:::note
在选择特定的仓位大小后，快速下单的按钮才能使用。
:::

按钮上的文字直接展示了它的功能。

- 左侧的Offer Bid按钮将使用订单簿当前的最高价格来下买单。
- 左侧的Offer Ask按钮将使用订单簿当前的最低价格来下卖单。
- Take Ask和Take Bid都是市价单，Take Ask相当于开多/减少仓位，Take Bid相当于开空/减少仓位。如果想使用挂单功能，则勾选“Post”。

订单将按照你的设置以市价单的形式来执行。快速下单按钮的具体设置能在系统设置里找到。

<div class="text--center">

![Settings-Quick](/img/trading/settings-quick.gif)

</div>

### 现价追单

:::note
这个功能目前只在测试版的Tealstreet软件里面提供。
:::

这个功能能够让交易者的限价单能追随市价而变动，能让交易者自动化他们的进场点和立场点。

<div class="text--center">
    <img src={LimitChasers} alt="Limit Chasers" style={{ width: 400 }} />
</div>

你可以在测试版软件的设置页面打开这个功能。

<div class="text--center">
    <img src={LimitChasersSettings} alt="Limit Chasers Settings" style={{ width: 400 }} />
</div>

:::caution
这个功能目前还在迭代，以后的功能可能会变化。
:::
:::note
目前这个功能会试2分钟，如果在1秒内订单没被执行则执行下一个最佳的订单簿价格。如果交易所取消你的订单，它会继续尝试，在1秒内去匹配下一个最佳的订单簿价格。
:::

### 止盈止损单

与交易所提供的止盈止损功能类似，Tealstreet也提供相应的功能，但是选项更多。

<div class="text--center">

![Stop-Orders](/img/trading/stop-orders.gif)

</div>

:::note
如果勾选“**Close on Trigger**”选项，则确保在目标价格到达并执行市价止损的时候不会开出一个反向订单。
:::

用户能提交市价或现价止损止盈单。两个窗口的设置和限价单设置界面类似，但功能更多。当设置止盈止损单的时候，用户需要制定订单被触发的方式：

- 指数价格：指数价格来自于多个现货交易所的价格，根据他们的权重进行加权计算。
- 最新价格：特定交易平台的最新价格。
- 标记价格：根据指数价格和基差的移动平均值加和计算而来。
- Close-On-Trigger：当目标价格到达时关闭仓位，并确保不开出反向仓位。

:::danger
一个限价止损单本质上只是一个触发器，如果价格达到它，就会在图表上放一个限制性的减价单。虽然限价对于获利有好处，但就退出您认为将对您产生重大不利影响的仓位来说，这并不理想。如果你想确定在价格达到时退出，你应该使用市价单。
:::

:::info
请访问各个交易所的网站来获得更多关于止盈止损单的信息。比如币安的页面**[Binance](https://www.binance.com/en/support/faq/what-is-stop-order-360036351051)**
:::

## 下订单设置

- 下订单设置窗口最近进行了升级

<div class="text--center">
    <img src={PlaceOrderSettings} alt="PlaceOrder Settings" style={{ width: 600 }} />
</div>

- 顶部是 "快速订单 "按钮尺寸，可让您准确调整订单尺寸。

- 接下来是快速偏移设置
    - **点数偏移**： 点数是资产订单的最小增量偏移大小
    - **百分比抵消**： 百分比抵消基于资产的当前价格
    - **波动抵消**： 所选时间段内资产 ATR 的测量乘数
    - **波动率时间框架 (ATR)**： 用于计算资产波动率 (ATR) 的时间框架
    - **活动快速订单类型**： 此设置可更改当前激活的模式

:::note
自定义这些设置后，您可以使用快速订单模块内的下拉选择器在快速订单模式之间轻松切换
:::
