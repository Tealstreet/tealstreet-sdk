## Webhooks

Webhooks 是一种扩展某些功能（如警报或执行订单）的方式。

---

### 创建一个 webhook

<div class="text--center">
    <img src={WebHooks1} alt="Web Hooks 1" style={{ width: 750 }} />
</div>

1. 首先，点击终端顶部的Webhooks链接。
2. 然后，点击新建Webhook按钮开始创建过程。

<div class="text--center">
    <img src={WebHooks2} alt="Web Hooks 1" style={{ width: 750 }} />
</div>

:::note
请注意，在 **[Runbot](/docs/webhooks/runbot)**的情况下，您需要选择一个适当的密钥，因为它们并不支持所有的交易所。例如，如果您正在使用**Binance** Runbot策略，您需要选择一个**Binance** API密钥。
:::

1. 首先选择您希望用于 webhook 的 API 密钥。
2. 给它一个名字，这只是为了您自己的参考。
3. 输入您选择的 API 密钥的加密密钥。
4. 选择一个过期日期。这是 webhook 将不再有效的日期。
5. 点击创建。

---

### 链接 webhook

一旦创建，您将收到一个带有 webhook URL 的弹出窗口。这是您需要用来将 webhook 链接到其他服务（如 Runbot）的 URL。

<div class="text--center">
    <img src={WebHooks3} alt="Web Hooks 1" style={{ width: 700 }} />
</div>

您应该妥善保管这些信息。

:::caution
您不应该与他人分享您的webhook。Tealstreet团队成员**永远不会**向您索取此信息。
:::

<div class="text--center">
    <img src={WebHooks4} alt="Web Hooks 1" style={{ width: 800 }} />
</div>

一旦激活并准备好使用，您的webhook在终端内部将看起来像这样。

:::tip
查看 **[Runbot](/docs/webhooks/runbot)** 文档，了解如何使用新创建的 webhook 的示例。
:::
