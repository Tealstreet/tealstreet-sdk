## 桌面客户端 - Mac OS

<div class="text--center">

![Apple](/img/client/Mac/apple.png)

</div>

本页面将介绍如何下载和安装Tealstreet桌面客户端。

- 前往Tealstreet下载页面（https://www.tealstreet.io/download/）下载Tealstreet桌面客户端。

- 如果您有 **M1** Mac，请单击“下载 M1 Mac 版”。

- 如果您有 **Intel** Mac，请单击“下载 Mac 版”。

<div class="text--center">

![Download-MacOS](/img/client/Mac/downloadmac.png)

</div>

短期内，Tealstreet Mac OS 桌面客户端没有代码签名证书，但我们正在通过批准流程，很快就会完成。

在 Mac 上，您将不得不在“系统偏好设置”->“安全性与隐私”->“通用”->“任何方式打开”中单击“任何方式打开”。

这是 Mac 上所有未签名代码的标准程序。 您可以从官方 Apple 网站上了解更多信息：https://support.apple.com/guide/security/gatekeeper-and-runtime-protection-sec5599b66df/web

您只需要进行一次此过程。 官方的苹果代码签名将很快解决。
