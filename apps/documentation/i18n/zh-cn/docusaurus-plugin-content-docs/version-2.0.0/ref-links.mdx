### 推荐链接

- Tealstreet 是免费使用的。我们通过与交易所的交易来赚钱。这不会给您带来任何额外的费用，因为它类似于推荐链接。
- 这就是所有加密货币交易终端的工作方式，尽管许多终端除此之外还向用户收取每月费用。
- 在 Tealstreet，我们相信，如果我们为我们的交易者提供良好的免费交易工具，那么我们将通过共享用户-Tealstreet 的增长而共同获得回报，而不必向我们的用户收取任何额外费用。

:::tip
通过使用我们的推荐链接之一，帮助支持 Tealstreet 的进一步发展：
:::
