在本指南中，我们将介绍如何加入The Shire Discord服务器以及一些有用的提示来减少垃圾邮件。

## 设置

如果您还没有帐户，请访问：https://discord.com/ 并创建一个帐户。您可以使用Web浏览器、移动应用程序或下载桌面客户端使用Discord。

创建帐户并登录后，单击链接以访问我们的Discord服务器：https://teal.link/discord

<div class="text--center">

![Discord-Main](/img/social/discord-guide/discord-main.png)

 </div>

接下来，您将看到The Shire Discord的欢迎屏幕。完成验证过程以获取访问所有频道和角色的权限。

<div class="text--center">

![Shire-Main](/img/social/discord-guide/shire-main.png)

</div>

完成验证后，随意浏览服务器并参与社区。

:::note
管理人员不会首先向您发送私信。请极度谨慎和谨慎地处理所有直接消息。永远不要通过直接消息共享或发送私人信息。
:::

## 提示

1. 如果您永远不想收到通知，请右键单击The Shire图标，然后导航到“静音服务器”栏。然后，选择适合您的时间段。

<div class="text--center">

![Tip-1](/img/social/discord-guide/tips-1.png)

</div>

2. 如果您收到垃圾邮件或可疑的直接消息，请通过关闭来自服务器成员的直接消息来增加隐私设置。

![Tip-1](/img/social/discord-guide/tips-2.png)

</div>
