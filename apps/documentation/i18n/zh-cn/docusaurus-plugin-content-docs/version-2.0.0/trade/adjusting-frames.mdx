# 调整框架和窗口

调整 Teal Street 交易界面的布局非常简单。

1. 如果您想更改窗口的大小或位置，请确保锁定图标显示为未锁定状态。

2. 现在，您可以使用光标拖动窗口以调整大小。单击并按住窗口的右下角，然后拖动以更改窗口大小。

<div class="text--center">

![Lock-Unlock](/img/trading/lock-unlock.gif)

 </div>

:::tip

您还可以使用光标移动整个窗口。单击窗口的右上角并将其拖动到所需位置即可。

:::
