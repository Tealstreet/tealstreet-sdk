**Aggr 模块** 提供了一个迷你浏览器，自动加载 [Aggr](https://charts.aggr.trade/) 的实例。

<div class="text--center">
    <img src={Aggr2} alt="Aggr 2" style={{ width: 350 }} />
</div>

Aggr 通过其极低的时间框架和 Tick 图表支持，是了解市场脉搏的绝佳方式。

---

### 启用 Aggr 模块

<div class="text--center">
    <img src={Aggr} alt="Aggr" style={{ width: 600 }} />
</div>

- 您可以在 **交易设置** 配置窗口的 **模块** 选项卡下启用 **Aggr** 模块。

:::tip
记得解锁您的布局以便移动模块。
:::

---

### 使用 Aggr 模块

<div class="text--center">
    <img src={Aggr3} alt="Aggr 3" style={{ width: 700 }} />
</div>

- 一旦激活并定位好位置，您可以点击右下角的 "**...**" 按钮来打开 Aggr 的选项。
