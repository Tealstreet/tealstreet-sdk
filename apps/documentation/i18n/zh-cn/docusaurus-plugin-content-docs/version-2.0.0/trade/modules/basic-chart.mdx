本节将介绍 Tealstreet 的 **基础图表模块**

<div class="text--center">
    <img src={BasicChart} alt="Basic Chart" style={{ width: 650 }} />
</div>

使用此工具，您可以在终端上放置任何 TradingView 支持的图表。

---

### 功能

- 可以使用顶部框架上的 + 按钮复制/删除窗口
- 顶部栏设置在刷新后保留
- 位置和大小保存在 TS 工作区布局中

    <summary>更多信息</summary>
    <div>
        <div class="text--center">
            <img src={BasicChart2} alt="基础图表（详细）" style={{ width: 500 }} />

        1. 加号按钮可用于复制或删除基础图表窗口 <br />
        2. 顶部标题（股票代码和时间框架）是唯一一个在刷新后保留其设置的部分。在图表内进行的更改不会被保留 <br />
        3. 当工作区被解锁时，您可以拖动底部角来扩展/缩小窗口。这些设置将作为当前活动的工作区配置文件的一部分保存 <br />
    </div>

### 其他信息

可以从 _[Sam 的博客文章](https://www.tealstreet.io/tealstreet-1-5-2-release-notes/)_ 中阅读一些其他信息

:::note
基础图表窗口是一个独立的窗口，可用于显示 TradingView 上任何工具的图表。它的常见用途是显示您感兴趣的其他工具的图表，例如指数或美元。
:::

:::caution
您将无法通过基础图表在主图表上交易头寸。
:::
