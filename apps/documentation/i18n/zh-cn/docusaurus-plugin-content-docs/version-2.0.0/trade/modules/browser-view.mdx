---

### 激活

通过转到您的Tealstreet设置来激活浏览器视图模块

<div class="text--center">
    <img src={CommonSettings} alt="通用设置" style={{ width: 350 }} />
</div>

然后启用浏览器视图模块

<div class="text--center">
    <img src={BrowserViewActivation} alt="激活浏览器视图" style={{ width: 350 }} />
</div>

:::note
浏览器视图不适用于Web浏览器内部。此功能仅适用于Tealstreet的桌面版本。（浏览器引擎的技术限制）
:::

---

### 用法

激活后，您可以通过单击顶部栏中的“打开浏览器视图”按钮来打开新的浏览器视图
