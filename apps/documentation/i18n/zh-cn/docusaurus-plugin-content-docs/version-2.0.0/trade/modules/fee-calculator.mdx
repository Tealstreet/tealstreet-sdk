### 启用手续费计算器模块

<div class="text--center">
    <img src={FeeCalc2} alt="手续费计算器2" style={{ width: 600 }} />
</div>

- 您可以在**交易设置**配置窗口的**模块**选项卡下启用**手续费计算器**模块。

:::tip
记得解锁您的布局以便能够移动模块。
:::
