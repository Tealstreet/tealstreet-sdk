Tealstreet **持仓量图表模块** 将打开一个预设的 [基础图表模块](/docs/trade/modules/basic-chart)，显示币安期货的持仓量图表。

<div class="text--center">
    <img src={OpenInterestChart} alt="Open Interest Chart" style={{ width: 600 }} />
</div>

### 激活持仓量图表模块

- 在终端设置的 **模块** 选项卡中激活它。

<div class="text--center">
    <img src={OpenInterestChartSettings} alt="Open Interest Chart Module" style={{ width: 350 }} />
</div>

激活后，您可以像其他模块一样调整其大小。

:::note
此模块目前仅适用于币安期货。
:::
