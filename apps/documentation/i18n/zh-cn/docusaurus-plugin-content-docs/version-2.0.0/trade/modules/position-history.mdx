## 持仓历史

**持仓历史** 模块是一种日志工具，可帮助您跟踪您的交易和持仓以及交易费用。这是一种很好的方式来跟踪您的交易表现，并在以后的日期回顾您的交易。

<div class="text--center">
    <img src={PosHistory} alt="Pos History" style={{ width: 1000 }} />
</div>

---

### 启用持仓历史

<div class="text--center">
    <img src={PosHistory2} alt="Pos History 2" style={{ width: 600 }} />
</div>

- 您可以在 **交易设置** 配置窗口的 **模块** 选项卡下启用 **持仓历史** 模块。

:::tip
记得解锁您的布局以便能够移动模块。
:::

---

### 使用持仓历史模块

<div class="text--center">
    <img src={PosHistoryUsage} alt="Pos History Usage" style={{ width: 1000 }} />
</div>

- 您可以单击交易旁边的加号 (+) 符号，以在交易时的图表快照中显示条目和持仓。
- 在 PnL 类别中，您可以单击弹出按钮以打开 [PnL 卡片](/docs/trade/pnl-cards)。

:::note
并非每个交易所都提供计算持仓历史所需的数据。如果您使用的交易所不提供此数据，则暂时无法使用此模块。
:::
