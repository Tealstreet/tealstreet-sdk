**Ticks Chart模块** 将允许您通过查看几乎每一笔交易来深入了解蜡烛图。

### 激活Ticks Chart模块

- 通过转到终端设置中的 **模块** 选项卡来激活它。

<div class="text--center">
    <img src={OpenInterestChart} alt="Open Interest Chart Module" style={{ width: 400 }} />
</div>

:::note
**Ticks Chart** 模块目前不支持交易。
:::
