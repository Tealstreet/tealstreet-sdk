本节将介绍**Twitter模块**，它将显示一个可以从设置窗口内的Twitter面板自定义的实时信息流。

### 激活Twitter模块

- 转到设置面板中的模块选项卡以激活它。

<div class="text--center">
    <img src={Twitter} alt="Twitter Module Activation" style={{ width: 450 }} />
</div>

<div class="text--center">
    <img src={SettingsTwitter} alt="Twitter Module" style={{ width: 700 }} />
</div>

:::tip
没有看到您喜欢的交易者？_[请告诉我们](/docs/support/contact-us)!_
:::

<div class="text--center">
    <img src={TwitterEye} alt="Twitter Eye" style={{ width: 600 }} />
</div>

:::note

- 您可以单击眼睛符号隐藏您不想看到的个别交易者。您可以通过单击**清除过滤器**按钮来重置您的过滤器。
- 您还可以单击此模块顶部的**Tree News**按钮以激活**新闻订阅**模块，以获取更多的新闻来源。
  :::

### 在Twitter中交易新闻

在最近的Tealstreet更新中，我们添加了根据**Twitter**和**新闻订阅**模块中的关键字下单的功能。这使您可以快速下单，而无需先拉出图表。这是一种可能更快地进入交易的方式。

- 您可以在终端设置页面的**模块**面板中激活新闻交易。

<div class="text--center">
    <img src={NewsTradingSettings} alt="News Trading Settings" style={{ width: 500 }} />
</div>

- 一旦激活并按照您的喜好进行自定义，您现在将能够从Twitter信息流模块中快速采取行动：

<div class="text--center">
    <img src={NewsTrading} alt="News Trading" style={{ width: 600 }} />
</div>

:::note
请小心使用此功能，因为如果您不小心，它可能会导致意外的交易。有时会出现与加密货币无关的推文，但仍可能触发检测系统生成交易按钮。我们正在努力改进此功能。
:::
