# 订单簿

这是 Tealstreet 的订单簿窗口。它根据您当前选择的加密货币和所选的交易所/API，在左侧显示当前的买单，右侧显示当前的卖单。

<div class="text--center">

![订单簿](/img/trading/orderbook.gif)

</div>

### 滑块

在窗口的左侧，您将看到一个蓝色的滑块条。移动滑块会根据加密货币调整买单/卖单的分组数量。例如，BTC 的范围从 0.5（最低）到 25（最高）。

<div class="text--center">

![滑块](/img/trading/slider.gif)

</div>

:::tip
滑块条的最佳设置取决于您交易的加密货币。对于像 XRP 这样的加密货币，您可能希望使用最低设置。对于 BTC，您可能希望使用更高的设置，但这取决于用户的偏好。
:::

### 买单和卖单

如果您单击订单簿的“买单”或“卖单”一侧的价格，这些价格将反映在下单框中。您可以通过单击黄色的 X 来取消单个未成交订单。

<div class="text--center">

![买单和卖单](/img/trading/bidsasks.gif)

</div>

单击蓝色的“订单”按钮将立即取消所有未成交订单。

<div class="text--center">

![全部取消](/img/trading/closeall.gif)

</div>
