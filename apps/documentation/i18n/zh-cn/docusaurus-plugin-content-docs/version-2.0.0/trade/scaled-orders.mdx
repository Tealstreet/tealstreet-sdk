## 分段订单

分段订单是一种算法工具，它使高级用户能够在用户确定的价格范围内自动创建多个限价订单。该工具还可以控制价格范围内订单的多样性和分布。

使用分段买入，当市场价格下跌时，低限价单会按顺序触发；分段卖出则相反，当市场价格上涨时，高限价单会依次成交。

:::tip
分段订单有助于避免在单笔交易中购买或出售大量合约的市场影响。它们还可以用于改善您的平均入场或出场价格。
:::

Tealstreet分段订单是一个非常强大的工具，您可以使用它来以任何您喜欢的方式分散您的买入和卖出订单。
