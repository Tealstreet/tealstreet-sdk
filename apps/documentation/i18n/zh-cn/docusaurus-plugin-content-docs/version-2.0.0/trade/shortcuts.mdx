### 快捷键定义

一旦启用，不同操作设置的快捷键将开始在终端中工作。以下是Tealstreet支持的快捷键列表：

| 快捷键       | 快捷方式               | 描述                                                                                                         |
| ------------ | ---------------------- | ------------------------------------------------------------------------------------------------------------ |
| S            | 以点击价格下限价单     | 在图表、深度图或订单簿上点击价格并按住以放置限价单（如果价格低于当前价格则买入，高于当前价格则卖出）。       |
| K            | 以点击价格买入         | 在图表、深度图或订单簿上点击价格并按住以放置限价买单                                                         |
| L            | 以点击价格卖出         | 在图表、深度图或订单簿上点击价格并按住以放置限价卖单                                                         |
| V            | 在点击价格处放置止损单 | 在图表、深度图或订单簿上单击价格并按住以放置止损单。如果您有一个活动订单，它将匹配现有订单的大小作为止损单。 |
| B            | 在点击价格处放置止盈单 | 在图表、深度图或订单簿上单击价格并按住以放置止盈单。                                                         |
| R            | 从图表下单             |                                                                                                              |
|              | 市价买入               | 在市价订单表单中提交市价买入订单。                                                                           |
|              | 市价卖出               | 在市价订单表单中提交市价卖出订单。                                                                           |
| Shift+A      | 下单买入               | 在下单模块中以当前价格下单买入。如果启用了缩放买入预览，则提交缩放买入。                                     |
| Shift+D      | 下单卖出               | 在下单模块中以当前价格下单卖出。如果启用了缩放卖出预览，则提交缩放卖出。                                     |
| A            | 取消最近订单           | 取消最近的订单。如果启用了缩放预览，则取消缩放预览。                                                         |
|              | 取消买单               | 取消当前活动市场的挂单买单。                                                                                 |
|              | 取消卖单               | 取消当前活动市场的挂单卖单。                                                                                 |
|              | 取消当前市场订单       | 取消当前活动市场的挂单。                                                                                     |
|              | 取消所有订单           | 取消所有活动账户的市场订单。                                                                                 |
| Ctrl+Alt+A   | 买入订单簿顶部         | 在订单簿的买入侧顶部下单。                                                                                   |
| Ctrl+Alt+D   | 卖出订单簿顶部         | 在订单簿的卖出侧顶部下单。                                                                                   |
| Ctrl+Shift+A | 买入订单簿第三层       | 在订单簿上显示的第三层下单买入。                                                                             |
| Ctrl+Shift+D | 卖出订单簿第三层       | 在订单簿上显示的第三层下单卖出。                                                                             |
| Z            | 从图表设置订单价格     | 按住并单击图表以自动填充下单模块中的价格。                                                                   |
| E            | 切换跟踪价格           | 在下单模块中切换跟踪价格复选框。                                                                             |
| Q            | 切换仅限挂单           | 在下单模块中切换仅限挂单复选框。                                                                             |
| W            | 切换仅限减仓           | 在下单模块中切换仅限减仓复选框。                                                                             |
| T            | 下单缩放预览           | 在图表上按住并单击两次以设置价格之间的缩放订单。                                                             |
| Alt+Shift+K  | 平掉头寸               | 关闭持仓表中列出的顶部头寸。                                                                                 |
|              | 平掉所有头寸           | 使用市价订单平掉所有开放头寸。                                                                               |
| A            | 将跟踪价格向远处移动   | 将跟踪价格偏移量在两侧远离订单簿顶部。                                                                       |
| D            | 将跟踪价格向近处移动   | 将跟踪价格偏移量在两侧靠近订单簿顶部的价格。                                                                 |
| N            | 修改单个缩放订单       | 按住以修改图表预览中的单个缩放订单。                                                                         |
| M            | 修改缩放订单块         | 按住以在预览中均匀移动所有缩放订单。                                                                         |
|              | 移动缩放订单块         | 按住以在预览中均匀移动所有缩放订单。                                                                         |
| K            | 打开图表符号搜索       | 直接打开 TV 符号搜索提示（以避免单击或按其他快捷键）。                                                       |
| H            | 自动填充持仓大小       | 自动将当前活动持仓大小填充到限价订单表单中。                                                                 |

您不必使用每个可用的热键操作来获得好处。尝试从使用您最常用的几个操作开始，并随着您变得更加熟悉而添加更多操作。

:::tip
热键是一种非常强大的工具，可以帮助您更快地交易，特别是在波动市场中。确保仔细查看提供的每个热键。
:::

要更改热键分配操作，只需使用光标单击要更改的操作旁边的键字段。然后，按下您想要分配的新键。无需按删除或退格键！

- 如果您进行更改并希望保存它们，请按蓝色的“确定”按钮。
- 如果您进行了更改但不想保存它们，请简单地按“取消”按钮。

:::tip
如果您难以记住操作和键分配，则一些用户报告成功，通过参考打印副本来解决这个问题。
:::

### 保留热键

:::caution

以下热键由主 Tradingview 图表保留。我们强烈建议**不要**将这些键设置为您的任何操作的热键/快捷键：

- Shift + B
- Shift + S

:::
