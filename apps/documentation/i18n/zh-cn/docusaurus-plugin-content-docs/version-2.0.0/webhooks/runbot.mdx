## Runbot

这部分将介绍如何将[Tealstreet Webhook](/docs/webhooks)链接到Runbot。

:::tip
请考虑使用我们的 **[Runbot 推荐链接](https://app.runbot.io/#QJQzXelz0w)**。
:::

:::note
Runbot有一个专门为Tealstreet量身定制的文档部分，你可以在 **[这里查看](https://docs.runbot.io/webhooks-alert-bots/tealstreet.io-free)**。
:::

---

### 将Tealstreet Webhook链接到Runbot

- 导航到 **[Runbot交易机器人](https://app.runbot.io/Bot/)** 页面。

<div class="text--center">
    <img src={RunBot1} alt="Runbot 1" style={{ width: 650 }} />
</div>

- 在这个例子中，你可以看到我已经创建了两个无限制的webhooks，并删除了另一个。根据你的计划或可用的token余额，点击链接添加新的webhook。

<div class="text--center">
    <img src={RunBot3} alt="Runbot 3" style={{ width: 400 }} />
</div>

- 为你的webhook提供一个名字。这完全取决于你的个人喜好。

<div class="text--center">
    <img src={RunBot2} alt="Runbot 2" style={{ width: 550 }} />
</div>

1. 首先加载你的策略。
2. 从警报下拉菜单中选择 Tealstreet。
3. 输入你在 Tealstreet 创建 Webhook 时获得的 webhook URL。更多信息请参见 [Webhooks](/docs/webhooks)。
4. 保存更改。

:::note
在你切换策略选择器下方的 **'运行此策略'** 开关之前，你的机器人还未开始运行。
:::

---

### 激活机器人策略

此时，如果你还没有调整你的策略，你应该进行调整。你可以在 **[这里](https://app.runbot.io/Strategies)** 导航到它。

<div class="text--center">
    <img src={RunBot4} alt="Runbot 4" style={{ width: 550 }} />
</div>

1. 选择你希望编辑的策略，或者如果你愿意，可以创建一个新的。
2. 根据你的情况和偏好编辑配置。

:::tip
并非每个交易所都受支持，因此请确保在此策略配置器中将适当的API密钥与正确的交易所匹配。例如，你不会想尝试使用**Phemex**的API密钥进行**Bitget**策略。
:::

根据你的喜好调整其他设置，例如何时进入或退出位置，以及目标利润和止损应该离开多远。

一旦这个设置完成，你可以回到Bot部分，切换'运行此策略'的按钮，保存后它将开始运行。

你可以在交易机器人页面上监控其状态，看看它的表现如何，它正在进行哪些交易以及何时进行。祝你机器人交易愉快！

:::note
如果你的设置不正确，你可能会在你注册的电子邮件地址上收到来自Runbot的邮件，其中包含了出错的额外信息。
:::

:::tip
如需获取有关如何使用Runbot的更多信息，请参阅 **[他们的文档](https://docs.runbot.io/)**。
:::
