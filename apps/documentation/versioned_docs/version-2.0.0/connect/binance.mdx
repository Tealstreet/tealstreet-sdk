## Connecting [Binance](https://teal.link/Binance1) to Tealstreet

:::note
Binance users are required to complete KYC before creating new trading API Keys.
:::

:::caution
To Trade using your Binance account on Tealstreet, users must setup a Dual API key. Please review the [Dual API](/docs/2.0.0/connect/dual-api) section for more informaiton.
:::

- First, make sure you are logged into your [Binance](https://teal.link/Binance1) account.

- Second, log into your [Tealstreet](https://app.tealstreet.io/) account.

:::tip
Its a good idea to keep both Tealstreet and Binance tabs open.
:::

1. Once you have successfully logged into Tealstreet, navigate to the header titled **‘API Keys’**

2. Click the blue button titled **‘New API Key’**

<div class="text--center">
    <img src={AddingApi} alt="TS Adding Api" style={{ width: 550 }} />
</div>

- Choose Binance from the dropdown menu.

<div class="text--center">
    <img src={Dropdown} alt="TS Dropdown" style={{ width: 550 }} />
</div>

- Now you are ready to generate the API Keys within your Binance Account. Head on over to the Binance tab and:
    - Click on the User Icon.
    - Select **API Management** from the dropdown menu.

<div class="text--center">
    <img src={ApiDropdown} alt="API Dropdown" style={{ width: 550 }} />
</div>

- Choose System Generated and then click Next.

<div class="text--center">
    <img src={SysGen} alt="System Generated Key" style={{ width: 550 }} />
</div>

- Now you are ready to create the APIs you will need to Trade using Tealstreet. First we will start with the "Trading" API Key.

:::note
Please review the [Dual API](/docs/2.0.0/connect/dual-api) section for more informaiton as to why a Read-Only API is required for Binance users using Tealstreet.
:::

---

### Trading API

On the Create API page:

- Choose a name for your API Key. It can be helpful to choose a name like Trading-Tealstreet to distinguish between the Trade and Read APIs. You will only see this label on the Binance website.
    - When done click on the **Next** button to start the key creation process.

<div class="text--center">

![API-Create](/img/connect/binance/apicreate.png)

</div>

:::tip
You can get to this page directly by navigating to this [link](https://www.binance.com/en/my/settings/api-management)
:::

1. Once you have created the API Key on Binance, you need to click the yellow button titled ‘Edit Restrictions.

<div class="text--center">
    <img src={ApiRest} alt="API Restrictions" style={{ width: 550 }} />
</div>

- Now you are ready to choose the settings of your Trading API Key pair.

<div class="text--center">
    <img src={ApiMore} alt="API Details" style={{ width: 650 }} />
</div>

1. ‘API Key’ - This is the key that will be pasted it into the Key field on Tealstreet.
2. ‘Secret Key’ - This is the secret that will be pasted it into the Secret field on Tealstreet.
3. Select the ‘Enable Futures’ option. Do not enable any other permissions.
4. Copy the list of IP Addresses from Tealstreet and then paste them into the ‘Restrict access to trusted IPs only’ field on the edit permissions window of Binance.
    - You need to hit the confirm button after you paste in the IPs in order for them to save properly.
5. Click ‘Save’

:::caution
Users **MUST** use the **Whitelisted IP Addresses** when creating this API. Please Ensure all IP addresses are correct as shown in the **Tealstreet terminal** window (images below/above are for reference only)
:::

<div class="text--center">

![API-Whitelist](/img/connect/binance/apiwhitelist.png)

</div>

:::note
After editing Key permissions, the dropdown arrow at the top right will minimize the editable fields. Once you minimize this area, you will no longer be able to see your **API secret**. Make sure you have it saved!
:::

:::caution
Never share your API Keys with anyone.
:::

Once you have created the API Key on Binance’s website, you are ready to fill out the information on Tealstreet’s API KEYS page.

1. Ensure you have selected ‘Binance’ in the Exchange dropdown menu.

<div class="text--center">
    <img src={TradeApi} alt="Trade Api" style={{ width: 650 }} />
</div>

2. Consider using the Tealstreet referral link to help support Tealstreet development.

3. Choose a name for this API connection. You will see this name on an API dropdown list on the trading page of the Tealstreet terminal. This is helpful for traders who utilize multiple accounts and/or sub accounts per exchange and want to distinguish between them.

4. Choose your Encryption Password. Remember to save this somewhere!

5. Paste the Trade API Key provided by Binance here.

6. Paste the Trade API Secret provided by Binance here.

:::caution
Do NOT press confirm yet, we need to create a **[Read-only API key](#read-only-api)**.
:::

Now that we are ready to create the **Read-Only** API key lets return to the Binance tab we opened earlier.

- Click on the User Icon.
- Select **API Management** from the dropdown menu.

<div class="text--center">
    <img src={ApiDropdown} alt="API Dropdown" style={{ width: 550 }} />
</div>

---

### Read-Only API

:::note
Please review the [Dual API](/docs/2.0.0/connect/dual-api) section for more informaiton as to why a Read-Only API is required
:::

On the Create API page:

- Choose a name for your API Key. It can be helpful to choose a name like Read-Only-Tealstreet to distinguish between the Trade and Read APIs. You will only see this name on the Binance website.
- Click on the **Create API** Button to start the key creation process.

<div class="text--center">

![API-Create](/img/connect/binance/apicreate.png)

</div>

:::tip
You can get to this page directly by navigating to _[this link](https://www.binance.com/en/my/settings/api-management)_
:::

- Once you have created the API Key on Binance, you need to click the yellow button titled ‘Edit Restrictions.

<div class="text--center">
    <img src={ApiRest} alt="API Rest" style={{ width: 1000 }} />
</div>

- Now you are ready to choose the settings of your Read-Only API Key pair.

<div class="text--center">

![API-Detailed](/img/connect/binance/api-read.png)

</div>

- Ensure that only "Reading" and "Unrestricted" are selected
- ‘API Key’ - This is the key that will be pasted it into the Key field on Tealstreet.
- ‘Secret Key’ - This is the secret that will be pasted it into the Secret field on Tealstreet.
- Click ‘Save’
- Once you have created the API Key on Binance’s website, you are ready to fill out the information on Tealstreet’s API KEYS page.

<div class="text--center">

![Trade-Tealstreet](/img/connect/binance/dualapi-nowhite.png)

</div>

- Once you have all the information filled out including both API keys. Press Create.

- If all the details are correct, you will have successfully linked your Binance account to Tealstreet. Navigate to the **Trade** page of Tealstreet and select the Binance account from the dropdown menu. If properly linked, you will see your balance/collateral appear in the Margin window of Tealstreet.

:::note
Be sure not to confuse API Key and API Secret. Connecting your Binance exchange account to Tealstreet will not work if these fields are not entered correctly.
:::

## Troubleshooting

In this section we will go over some of the Binance specific issues that may arise.

### Error about unable to adjust margin mode

<div class="text--center">
    <img src={UnifiedAssets} alt="API Dropdown" style={{ width: 400 }} />
</div>

- For now Tealstreet only supports single-asset-mode not the new multi-asset-mode. See [more here](https://www.binance.com/en/support/faq/how-to-switch-between-single-asset-and-multi-assets-modes-de2681ac63714c7d84a685967f7c1a53)

### Error about order position side not matching

<div class="text--center">
    <img src={PositionSide} alt="Position Side" style={{ width: 400 }} />
</div>

- Please double check your hedge mode vs one-way settings.

### Error about "Trading key - invalid api key, ip, or permissions for action"

<div class="text--center">
    <img src={AccountTypeError} alt="wrong account / permission type" style={{ width: 400 }} />
</div>

- Please ensure you are using a futures trading account. Tealstreet does not currently support spot trading.
    - Also please ensure you selected the correct permissions for the API key.
