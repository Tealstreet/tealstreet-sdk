### Mac Desktop

<div class="text--center">

![Apple](/img/client/apple.png)

</div>

This page will go through the download and installation of the Tealstreet Desktop Client.

- Head on over to the tealstreet download [page](https://www.tealstreet.io/download/) to download the Tealstreet Desktop client.

- If you have a **M1** Mac, click 'Download on Mac M1'

- If you have an **Intel** Mac, click 'Download on MacOS'

<div class="text--center">

![Download-MacOS](/img/client/downloadmac.png)

</div>

:::note
Or you can use [Tealstreet in your browser](https://app.tealstreet.io/trade)
:::

Tealstreet's certificate has been signed by Apple it just has not built into the application yet. In the meantime, you will have to go through a few extra steps to install the application.

On Mac, you will have to click on "Open Anyways" in System Preferences -> Security & Privacy -> General -> Open Anyways

This is standard procedure for all unsigned code on Mac. You can read more about this from the official Apple site: https://support.apple.com/guide/security/gatekeeper-and-runtime-protection-sec5599b66df/web

You will only have to go through this process once. Official code signing from Apple will be resolved soon.
