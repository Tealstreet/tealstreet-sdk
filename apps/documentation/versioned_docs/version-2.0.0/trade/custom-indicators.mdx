With the 2.0 update Tealstreet now supports community made custom indicators created in PineJS. This section will go over some examples that are already made, and how you can make your own and get them added into Tealstreet if you wish to do so.

### Custom Indicators in Tealstreet

<div class="text--center">
    <img src={CustomIndicators} alt="Custom Indicators Example 2" style={{ width: 300 }} />
</div>

- In this screenshot you can see 3 indicators a community member [Zande](https://github.com/lmvdz) has already submitted

:::tip
Note that these indicators are not as powerful as the native TradingView indicators. **PineJS** is a less powerful & simplified version for third-party developers to use.
:::

### Getting your custom indicator added to Tealstreet

<div class="text--center">
    <img src={CustomIndicatorsUpload} alt="Custom Indicators Github" style={{ width: 700 }} />
</div>

- You can submit a PR to our **[Github](https://github.com/Tealstreet/tealstreet-tv-studies)** with your custom indicator. However please be sure to include an MIT License header at the top of your code. If you do not include this we will not be able to accept your PR.
