The **Aggr module** hosts a mini browser that automatically loads up an instance of [Aggr](https://charts.aggr.trade/)

<div class="text--center">
    <img src={Aggr2} alt="Aggr 2" style={{ width: 350 }} />
</div>

Aggr is an excellent way to keep your finger on the pulse of the market with its extremely low timeframes and tick chart support.

---

### Enabling the Aggr module

<div class="text--center">
    <img src={Aggr} alt="Aggr 1" style={{ width: 600 }} />
</div>

- You can enable the **Aggr** module under the Modules tab in your **Trade Settings** configuration window.

:::tip
Remember to unlock your layout to be able to move the module around.
:::

---

### Using the Aggr module

<div class="text--center">
    <img src={Aggr3} alt="Aggr 3" style={{ width: 700 }} />
</div>

- Once activated and positioned how you like you can click the "**...**" button in lower right hand corner to bring up aggr's own options
