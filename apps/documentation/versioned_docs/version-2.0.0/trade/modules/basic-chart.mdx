This section will go over the **Basic Charts module** of Tealstreet

<div class="text--center">
    <img src={BasicChart} alt="Basic Chart" style={{ width: 650 }} />
</div>

With this tool you can put any chart supported by tradingview on your terminal.

---

### Functionality

- Can duplicate/remove windows with the + button at top of frame
- Top bar settings persist through refreshes
- Position & Size saved in TS workspace layout

<details open>
    <summary>More info</summary>
    <div>
        <div class="text--center">

        1. The Plus button can be used to duplicate or remove a Basic Chart window <br />
        2. The top header (Ticker & Timeframe) is the only section that preserves its settings across refreshes. Changes
        made inside the chart will not be preserved <br />
        3. When the workspace is unlocked you can drag bottom corner to expand/shrink the window. These settings will be
        saved as part of the workspace profile that is currently active <br />

---

### Additional Information

Some additional information can be read about here from the _[blog post by Sam](https://www.tealstreet.io/tealstreet-1-5-2-release-notes/)_

:::note
The Basic Chart window is a standalone window that can be used to display a chart of any instrument on TradingView. A common use of it is to display a chart of some other instrument you are interested in such as an index or the dollar.
:::

:::caution
You will not be able to trade positions on the main chart through the basic chart.
:::
