Tealstreet **Open Interest Chart Module** will open a preset [Basic Chart module](/docs/trade/modules/basic-chart) with the Open Interest chart of Binance Futures.

<div class="text--center">
    <img src={OpenInterestChart} alt="Open Interest Chart" style={{ width: 600 }} />
</div>

### Activating the Open Interest Chart module

- Activate it by going to your **modules** tab in the terminal settings.

<div class="text--center">
    <img src={OpenInterestChartSettings} alt="Open Interest Chart Module" style={{ width: 350 }} />
</div>

Once activated you can resize it like any other module

:::note
This module is currently set for Binance Futures.
:::
