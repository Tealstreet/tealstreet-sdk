The **Ticks Chart Module** will allow you to drill down into a candle by seeing virtually every trade that occurs.

### Activating the Ticks Chart module

- Activate it by going to your **modules** tab in the terminal settings.

<div class="text--center">
    <img src={OpenInterestChart} alt="Open Interest Chart Module" style={{ width: 400 }} />
</div>

:::note
The **Ticks Chart** module does not currently support trading.
:::
