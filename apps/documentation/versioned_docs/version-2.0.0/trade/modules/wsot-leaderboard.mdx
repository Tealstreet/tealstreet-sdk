---

### Activating the WSOT Leaderboard module

- You can activate this from the **Modules** panel in the terminal settings window.

<div class="text--center">
    <img src={WSOTLeaderboardModule} alt="WSOT Leaderboard Module" style={{ width: 350 }} />
</div>

The WSOT Leaderboard will show the following information:

- Rank
- Uername
- PnL
- Volume

:::tip
You can click the button at the lower right of the module to show more then 10 ranks.
:::
