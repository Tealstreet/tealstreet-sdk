# Crypto.com negative joins

Production and UAT run real Session/Registry/native private-startup proof/remote
signer/HPKE controls with unchanged permanent refusal, original binding and fully
loaded resident/provider/owner/registration/holdings/zero-write assertions.

Private startup is a closed set of four read-only POST methods with empty params.
The independent fixture checks HMAC over method, id, key and nonce, fresh u64
nonce equal to id, native API prefix and origin, and echoes the request id.
Private socket subscriptions require per-upgrade authentication; bad re-auth
revokes it. Public discovery and heartbeat never establish possession.
Replay targets private REST, with old/new signing bytes required to differ and
fresh socket prerequisites. Two genuine credential pairs remain independently
valid. Actual wire controls cover native JSON auth and connection isolation.
No production admission, helper, catalog, origin, codec or live venue changes.

The unchecked-auth checkpoint must compile and expose three invalid HTTP
controls plus a real wrong-key Session attaching an unproved socket before
verification is wired in a separate commit.
