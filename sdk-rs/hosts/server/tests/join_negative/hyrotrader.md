# HyroTrader negative joins

Mainnet uses real Session/Registry/native private-startup proof/remote signer/HPKE
with unchanged permanent refusal, original binding and fully loaded resident,
provider, holdings, owner/generation, registration and zero-write assertions.
Both hosted testnet modes refuse before signing, private I/O or attachment;
no unsupported sandbox is invented.

The fixture reuses only the native Bybit-linear response corpus, independently
pins the HyroTrader upstream origin and checks singular key/stamp/window/MAC
headers with fresh canonical time and HMAC over the original query. Responses
advance venue time because the native engine calibrates its protocol clock.
Private subscriptions require fresh per-socket authentication using the actual
all-string key/expiry/MAC tuple. A bad re-auth revokes that socket's authority;
other sockets never inherit it. Unknown operations fail instead of trading.

COSIGNED wrong-key and REST replay controls receive a fresh correct socket
handshake, isolating the actual private-read refusal as the native probe does;
bad WS material/expiry have separate loopback controls. DELEGATED uses the real
local provider and sealed material. The ambiguous HyroTrader 10003 diagnostic
reason remains unchanged; these fixtures do not diagnose an IP/key defect.

The unchecked checkpoint is compiled before verifier wiring: positive passes,
three invalid verifier controls fail, and the actual wrong-key Session must
fail with an unproved socket attached. No helper, production, catalog, origin or
signing-codec changes or live venue certification are implied.
