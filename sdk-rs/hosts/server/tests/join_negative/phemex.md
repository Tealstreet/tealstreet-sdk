# Phemex negative joins

Two configured network cohorts exercise the real Session, Registry, private
startup proof, remote signer and HPKE handover paths. The fixture recognizes only
native public discovery, USDT/USDC account-position reads, read subscriptions and
socket authentication. Unknown operations fail instead of issuing trading writes.

This is the deliberate red checkpoint: HTTP and socket authentication are
initially unchecked. Transport-verifier negatives and the real wrong-key Session
case must compile and fail before independent HMAC/expiry checks are wired.
The shared refusal and resident-preservation assertions stay unchanged.

The per-upgrade socket closure starts unauthenticated and sends private snapshots
only after authentication. Actual native-shaped u64 login, both valid pairs,
pre-auth subscription, malformed credentials and authentication reset have a
loopback wire control. REST replay crosses a real 1100 ms expiry boundary; socket
prerequisites always receive fresh signatures. No live venue certification,
catalog/origin activation or shared-helper changes are implied.
