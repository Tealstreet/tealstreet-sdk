# WOO negative joins

Mainnet and staging run the production Session, Registry, native private-startup
probe, remote signer and HPKE handover with unchanged permanent bound-refusal and
loaded resident/provider/owner/registration/holdings/zero-write assertions.

The independent fixture implements the configured legacy v1 query-plus-timestamp
and v3 timestamp/method/full-target HMAC recipes. Private reads and socket auth
require genuine material, singular headers and fresh timestamps. Per-upgrade
socket state gates private subscriptions and is revoked by a bad re-auth.
Only configured startup reads and read-only socket traffic are accepted.
REST replay retains the operation parameters and waits for different signing
bytes; fresh socket prerequisites are answered normally. No live venue
certification, catalog/origin activation or shared-helper change is implied.

The initial unchecked-auth checkpoint is compiled before verification wiring.
Its positive control passes, three invalid verifier controls fail, and the real
wrong-key Session test fails because an unproved socket attached.
