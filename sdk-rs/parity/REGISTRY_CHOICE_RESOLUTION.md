The rationale review added a previously unpriced object-level cost: source
registry values can be changed as ordinary objects. This is separately observed,
not inferred from checking94 ordinary routes. The new supplement executes the
actual maintained source initializers using the existing capture helper. It
checks seven export values for each platform, one mutation sequence for each
registry object, and a discarded web Promise continuation:17 source cases.
The exported-value cases include scalar/plain-object admission and thenable
adoption, plus constructor static/prototype fields. Native static signatures are inspected for their admitted capability
and error types; there is no claim of a runtime arbitrary-export validator.

The supplement runs both native cancellation schedules before its source
capture. The loader target now reads all47 descriptor name/module/constructor fields directly against decoded
source observations, alongside the existing94 executed entry paths. Two explicit
native schedules drop an unpolled web future with an unsettled or settled
host; both retain
only the eager import effect. The source discarded-Promise witness settles its
host and drains four microtask turns before observing its export access. This
is a bounded schedule, not a general event-loop or cancellation equivalence.
Existing fixture bytes and the original source capture helper are preserved.

The source mutation sequences replace the first loader, add one own property
and replace each local registry object's prototype. They do not modify the
global Object.prototype. The export fixtures control only the first ApexOmni
entry for each platform; ordinary module/export route checks cover all94.
Those selected malformed-host values are evidence of the adapter price, not
proof of a production ApexOmni error or a venue-specific implementation defect.

Native production consumers of these module-host interfaces were not found
outside registry code/tests in this bounded read. The facade owns a separate
constructor type. Supplied host factories, all concrete venue constructors and
complete facade/platform linking remain outside the proof. Typed constructor
capabilities must not be reported as completed static venue linking.
