Two independent read-only sub-agent reviews inspected all eleven source/native
pairs. Neither established a new defect within the declared own-data, byte and
native capability inputs. Review required three wording corrections: source
runtime discovery happens during later clock synchronization, Blob receiver
behavior is outside the byte-future interface rather than converted to errors,
and no Rust dependency-cycle necessity is established for the clock transport.
The actual native default timer hook drops work instead of scheduling it.

This is a rationale resolution, not an assertion that every production host is
bound. Native production call sites established in this bounded read are the
unknown-outcome classifier in chaser_engine and shared clock reads in Store.
Similarly named host methods do not establish bindings to these utilities.
Startup environment capture, all byte-source factories and browser/worker
runtime assembly remain unproved. The clock oracle injects failing network and
transport hooks; it cannot prove the actual proxy URL or 5000ms timeout binding.

Native evidence comes from the existing store/crypto remaining_utils test files
and a scoped clock unit target. Native assertions preceded the separately invoked
maintained-source oracles. The standalone utility oracle is not called by the
Rust remaining_utils targets. The clock source checker is a separate nineteen-
case frozen-corpus comparison; its file is preserved. Exact measured commits,
commands, exits, controls and exclusions are recorded in
UTILITY_CHOICE_GATE_EXITS.md, including the initial fixture-path failure.
No historical snapshot is regenerated to obtain a pass.

The first utility-source invocation failed with ENOENT because its oracle used
a worktree-local node_modules path. The oracle now resolves the same nanoid
6.0.1 dependency through the existing dependency host and pins that version;
its algorithm and expected sample remain unchanged. A separate source gate
checks literal payload expectations and the clock completion marker, so an
empty successful producer is not accepted. This is one oracle portability
repair plus producer guards, not an SDK runtime repair. No Rust test changes.
