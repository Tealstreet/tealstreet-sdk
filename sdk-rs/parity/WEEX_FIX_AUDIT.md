# WEEX: exact 23-row FIX audit

Frozen assignment: `assignments/codex-4ri6pb.json` (23 WEEX rows). Production baseline: `a8699f238f`; unchanged-body compiled RED preparation: `2373123bf0`.

## Result and limits

Three FIX rows lose valid public data because the native adapter captures unread input before using the source fields. The source has no such reads. The production fix evaluates candle properties and two-value book destructuring directly over canonical Js, preserving evaluation order and the canonical book-total operation. Candle stays typed f64. Eleven scalar rows remain FIX-OWNED by codex-umke5m for the shared depth bound; that lower boundary can still lose real pages. Nine ACCEPT rulings price the assigned runtime/typed-interface/assembly claim, based on real consumers below. Independent strict per-row output policy, UTF16, ownership and numeric-ingress profiles are not silently removed. In particular this audit supplies the shared numeric-bound owner with an observed depth128 counterexample; it does not approve losing pages at that bound.

## Executed evidence

- `tests/fix-audit-source.cjs`: full maintained constructor, DefaultStore and API; only terminal Axios is scripted. Thirteen fixed profiles; includes unread depth150 properties and tuple tails. Native `fix_audit_utilities_run_through_whole_source_and_constructed_native_methods` replays all thirteen through actual HTTP/SDK methods. Candle numeric fields, ticker percentage and a book level are inspected as native f64 bits before finite result projection. JSON number spelling is normalized only for the final finite view comparison.
- `tests/fix-audit-refresh-source.cjs`: full maintained private class, parent REST/API and Store; deterministic timer registration and held terminal HTTP. Six profiles, all three kinds live/disposed. The constructed native `fix_audit_real_private_refreshes_debounce_await_and_skip_disposed_store` uses actual private frames, canonical runtime timers, held HTTP and the real Store. Disposal resets Store; the assertion is no repopulation after settlement, not preservation of pre-disposal rows.
- `tests/eager_sdk_binding.rs`: dropped typed waiter still executes both signed order reads (#1059); real no-market mode change runs its Store prefix before polling.
- Existing `exchange_binding` mixed/all-refused market/fill pages, source-error precedence, auth, sockets, callbacks and disposal are executed. `classes`, `private_feed`, `record_boundaries`, `utils_oracle`, `candles` and `orderbook` remain independent bounded contract evidence, not substitutes for the actual composition probes.
- Original-body compiled RED3 in `/tmp/port-txflow-weex-unread-red.log` (three named WEEX-AUDIT assertions; no compiler failure). The permanent control runner reinstalls that immutable original adapter range, requires RED3, restores exact bytes, and requires all five new constructed tests GREEN.
