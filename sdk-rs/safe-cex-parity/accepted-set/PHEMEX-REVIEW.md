# Phemex selected contract review

This slice reviews all 44 owners in the original native/default Phemex census.
The closed compiler-selected runner executes 30 decoder owners and emits 14
individual classification receipts. Each function contract retains the exact
compiler API, including generic bounds. No neighboring parser or helper inherits
a classification.

Four concrete record contracts inspect all seven account fields and 42 position
fields, native numeric bits, envelope metadata and positions cardinality. Their
adapters execute direct text, qualified owned/borrowed Deserialize and all three
existing numeric frontdoors. Complete valid positional arrays are rejected.
Three guard-only removal controls compile, fail the named complete-array
assertion and pass after exact restoration. The separate direct-envelope repair
and its old-derive mutation proof landed in #280. Existing typed-edge FINDING
rows and reserved envelope metadata boundaries remain unchanged.

Twenty-six function contracts execute 136 independently authored cases against
the actual native functions. They observe numeric bits/NaN, UTF-16 units, native
value kinds, first-match and fallback behavior, full ticker fields and output
cardinality, Store fallback, read/emitter traces, and rejection identity where
provided by the API. Host fixtures delegate language operations to the shared Js
carrier and panic on unrelated capabilities. Mapped-property fixtures cover
exact keys; they do not assert every possible host implementation or replace the
production binding's mapped-key contract. Object observations inspect native
fields recursively, including Number bits, rather than compare JSON numeric
lexemes after serialization. The source-carried missing-ticker-error defect is
retained and witnessed.

The classifications are twelve specific non-decoders and two typed state
initializers. Five text encoders, three endpoint lookups and the TypeError
constructor have nine direct unit witnesses and nine compiling mutation controls.
The outbound affix encoder, host label encoder and socket sender have three
additional direct unit witnesses and individual mutation controls. Endpoint
unknown-key panics retain their internal caller precondition. The sender witness
checks exact frame fields, params, negative-zero ID bits and host failure identity.
The two initializer classifications have separately executed actual-source/native
constructor witnesses in start_order_formatting and websocket_data. Classification
receipts do not replace these native executions.

From sdk-rs, run the closed selected census with:

```sh
node safe-cex-venue-phemex/scripts/accepted-census-contracts.mjs
```

This performs fresh rustdoc, authenticates the selected names against compiler
inventory, loads the per-crate contract directory and calls the canonical native
production probe runner. It fixes both the selected identities and the expected
30/14 runtime/classification counts. The helper proposal report is never used as
executable contract input. Separate proof commands are:

```sh
cargo test --locked --jobs 1 -p safe-cex-venue-phemex --lib accepted_
python3 safe-cex-venue-phemex/scripts/accepted-helper-controls.py
python3 safe-cex-venue-phemex/scripts/outbound-contract-controls.py
python3 safe-cex-venue-phemex/scripts/record-shape-controls.py
```

The original selected census is not full current package discovery. Newer
compiler discovery has 54 owners and one public alias. Ten post-census owners,
that alias, local scopes, feature combinations and WASM remain separate review
obligations. In particular, ordinary private Wire decoders retain their own
obligations; outer guards do not exempt them. The new Api construction.json row
reviews only its private Clone capability and explicitly does not claim executed
clone behavior or classify its decoder/signing methods. No whole-package or
whole-venue accepted-set completion is claimed.
