`BinanceSpotExchange` and `ExchangeState`. Fresh compiler inventory finds 53
entrypoints: 15/11/11/16 respectively. All 16 State entries execute native

input-role records do not claim decoder execution. The actual constructors are

The 46 observed entrypoints have 92 finite cases. They construct the production
classes with NativeImports, DefaultStore, the actual HTTP/API/signing factories,

current Store settings and actual configured request method/base/path/query order
