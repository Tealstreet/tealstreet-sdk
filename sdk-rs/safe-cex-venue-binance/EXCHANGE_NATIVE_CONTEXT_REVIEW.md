# Native exchange context contracts

This cohort adds exactly four executed contracts: ExchangeOwner, Context,
RestContext and emit_json. Their requiredFeatures native field delegates default
CI measurement to the maintained driver and its authenticated native compiler
inventory. The default receipt is native-gated, not executed decoder evidence.

The native constructor creates the real NativeImports, BaseExchange, Store,
HTTP clients and public/private children. Its witness reads typed handle presence,
checks both original child Rc identities, invokes the actual Deref and compares
parent state identity. A real signed Futures/PM GET then verifies the configured
client URL, endpoint and returned body; the native handles themselves are opaque.
The constructor is checked to issue no HTTP before that explicit observation.
Deref has a typed capability role, not raw admission, and is executed within this
constructor observation.

Context invokes each inventoried SnapshotBindings method on the real parent:
get through signed native HTTP, market lookup through the production Store facade,
and client-ID matching through the existing Order typed boundary. The valid Order
profiles include lastUpdate. No malformed/partial Order admission equivalence is
claimed. Snapshot reaction ordering is outside these single-request observations.

RestContext invokes its public candle GET with present/absent limit, preserving
the source query key order. Returned JSON carrier fields and number bits are read
before the observation is serialized. emit_json invokes the existing shared Base
reporter and reads actual event UTF16, raw reporter fields/number bits and original
console/reporter object identity. Its six-profile whole-class/source evidence
remains in json_error_binding; this finite function contract adds three direct
input profiles. No HTTP request occurs for that direct error-emission operation.

The source/codec boundaries are unchanged. No production method is replaced in a
witness and no fake ExchangeImports implementation is supplied. Only terminal IO
and runtime scheduling ports are scripted by the existing native host fixture.
The 15 native cases are bounded execution evidence, not arbitrary graph, every
generic instantiation, native/wasm equivalence or complete venue parity claims.

Initial measurement: fresh native missing-classification RED4, followed by actual
native GREEN4/15, zero classification-only receipts, full197 dependency discovery.
The companion exchange-native-controls.py requires four independently compiled
semantic faults to fail only their named owner, exact source restoration and
native GREEN4 after each. Controls and final feature-delegation/gates must pass
before READY; the initial positive measurement alone is not a READY receipt.
