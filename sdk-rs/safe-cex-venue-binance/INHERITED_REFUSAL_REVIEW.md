# Inherited native refusal witnesses

Eight source methods use BaseExchange's genuine Not implemented refusal:
Futures max leverage; PM max leverage/public trades; Spot max leverage/public
trades/leverage/position mode/margin type. The full maintained constructors,
actual Axios factories/Store and real methods produce 16 refusal profiles with
zero HTTP, emitted errors and telemetry reports. Terminal HTTP is guarded.

The native target constructs the actual three native SDK classes using
native_dependencies and the existing primitive HTTP/WS/runtime fixture. It calls
each actual Exchange method with the same two argument profiles. Native Error
name/message and I/O/event/report counts are read directly before JSON. The
ignored source test executes the maintained constructors afresh and compares
all16 records. This is bounded real-host evidence of inherited behavior; it is
not a decoder admission or arbitrary thrown-value/feature-matrix claim.

Run inherited_refusal_binding with native and --include-ignored from sdk-rs,
providing SAFE_CEX_TYPESCRIPT_PATH for the existing isolated dependency directory.
The independent compiled control runner is scripts/inherited-refusal-controls.py.
It mutates each actual inherited method, requires that method's named native
assertion failure, restores exact source bytes and requires a pass. Compiler
failures do not satisfy a control. Final source/native comparison must pass.

The initial source/native run passes9 tests (16 profiles). Eight independent
controls are pending; this preparation does not yet add constant-output policy
or classify the remaining class decoder APIs. A reviewed exact-source policy
extension needs to retain compiler API/span, source and fixture hashes, distinct
genuine inputs and actual inherited refusal/zero-HTTP assertions.
