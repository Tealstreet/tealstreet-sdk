## Ticker subscriber rejection

The declaration exemption was legitimate; its production callback was not. `PublicProtocol::register_handlers` previously constructed a fresh message-only `ExchangeError`. It now passes `TickerEventError::Store` through the existing Store-to-ExchangeError conversion. The source-coercion branch retains its previous behavior.

Baseline ef028537e9 with only the new registry regression compiled and failed at `native socket retains error name: Bybit` (`Error` versus `TickerSubscriberError`). The preceding assertions confirmed that the ticker update committed and later subscribers were skipped. Baseline receipt: `/tmp/bybit-ticker-registry-before.log`. The fixture script executes the maintained TS ticker methods for all three socket classes and asserts original thrown object identity plus committed state. This is separate from its 1,458 numeric/coercion cases.

Fixed receipt: `/tmp/bybit-ticker-registry-after.log` passes the four-constructor registry witness. The all-features `production_cancellable_future_classifications_are_current` target passes (214 reviewed production creators), and scoped Rust formatting passes. Independent source/test review found no correctness or reuse issues.
