Borrowed UTF-16 units preserve all string comparisons, including unknown strings,
unpaired surrogates and pairs. Every non-string source value takes the default
without coercion; None represents that comparison-equivalent class. This does
not reject or replace a string, narrow the string domain, or require a second
executable object model. The returned finite native enum variants cover every
source return. There is no chosen UTF-8 limitation in these helper signatures.

The source witness transpiles and executes the complete checked-in logging,
shared types, venue types and exchange modules. Constructor-only stubs permit
allocation of the real class; its actual mapping fields are called unchanged.
Unclaimed dependency consumers throw if called. The constructor itself is not
ported or behaviorally claimed.

enums, six method names, UTF-16 input units, non-string labels, per-group counts
`[28,28,28,26,25,26]`, and **161 executed native comparisons**. Native variants
are asserted directly, independently of Serialize/Deserialize; no output wire
comparison or decode/reencode roundtrip substitutes for those assertions.
Inputs include all declared enum values, unknown/case-mismatched strings, empty
strings, lone high/low surrogates, a valid pair, surrogate-prefixed/suffixed known
values, and 14 non-string cases including undefined, null, boxed strings,
Symbol, BigInt, functions and a throwing coercion hook. The actual-source hook
