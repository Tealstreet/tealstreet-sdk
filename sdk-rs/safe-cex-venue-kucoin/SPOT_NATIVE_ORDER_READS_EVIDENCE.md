normal completion does not. The floor does not cover arbitrary iterator step
failures, throwing close methods or all getter/emitter abrupt completions.

The finite fixture uses dense arrays, ordinary objects and scalar strings.
Its local language additions model data destructuring on the tested object
responses, subtraction, and dense reduce with initial accumulator. It does not
establish arbitrary proxies, sparse-array deletion, descriptors, inherited

engine/transport integration. Those unproved domains do not disappear from the
retained typed-route notes. No actual shared Store prototype-write repair is
claimed. Opaque production values/errors remain supplied standard-language
handles, while this fixture represents transport errors as Rc strings.
